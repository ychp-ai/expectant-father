# Expectant Father：准爸爸孕期行动手册

这是一个面向准爸爸和家庭的孕期管理知识库，目标是把孕期信息整理成清晰的时间线、行动清单、检查指南和记录模板。

> 说明：本项目内容仅用于孕期管理参考，不能替代医生诊疗意见。不同地区、医院和个人情况可能存在差异，请以产科医生建议为准。

## 项目定位

本项目关注四件事：

- **时间**：现在处于哪个孕周，接下来会发生什么。
- **任务**：这一周需要完成什么、预约什么、准备什么。
- **知识**：每项检查、症状、物资和手续的背景说明。
- **记录**：产检、体重、血压、胎动、医生建议和待办事项。

## 如何使用

建议按两种方式阅读：

1. **按孕周阅读**：从当前孕周进入，查看本周状态、重点事项和记录区。
2. **按专题阅读**：需要了解检查、物资、证件、风险或爸爸任务时，进入对应专题。
