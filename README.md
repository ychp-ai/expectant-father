# Expectant Father

准爸爸孕期行动手册。

本项目把孕期管理拆成几个可执行模块：按孕周了解当前阶段，按行动计划推进任务，按专题准备产检、爸爸任务、物资和办事事项。

> 提醒：本项目用于家庭准备、记录和沟通，不替代医生、医院或当地官方要求。

## 快速入口

| 模块 | 用途 | 入口 |
|---|---|---|
| 孕期管理总览 | 查看整体孕期管理框架 | [孕期管理总览](./孕期管理文档.md) |
| 孕周文档 | 按第 1～40 周查看每周状态和记录 | [孕早期](./docs/孕期管理/孕早期/第01周.md) / [孕中期](./docs/孕期管理/孕中期/第13周.md) / [孕晚期](./docs/孕期管理/孕晚期/第28周.md) |
| 行动计划 | 按阶段查看“什么时候做什么” | [行动计划](./docs/02-行动计划/README.md) |
| 产检指南 | 查看常见产检项目的准备和记录 | [产检指南](./docs/03-产检指南/README.md) |
| 爸爸指南 | 查看准爸爸各阶段任务 | [爸爸指南](./docs/04-爸爸指南/README.md) |
| 物资准备 | 管理待产、到院和回家物资清单 | [物资准备](./docs/05-物资准备/README.md) |
| 办事指南 | 管理建档、资料、费用和后续事项 | [办事指南](./docs/06-办事指南/README.md) |
| 执行清单 | 把任务变成可勾选清单 | [执行清单](./docs/07-执行清单/README.md) |

## 推荐使用顺序

1. 从 [行动计划](./docs/02-行动计划/README.md) 找到当前孕周阶段。
2. 根据行动计划进入对应的 [产检指南](./docs/03-产检指南/README.md)。
3. 准爸爸同步查看 [爸爸指南](./docs/04-爸爸指南/README.md)。
4. 孕中晚期开始维护 [物资准备](./docs/05-物资准备/README.md)。
5. 出生前后持续维护 [办事指南](./docs/06-办事指南/README.md)。
6. 每周使用 [执行清单](./docs/07-执行清单/README.md) 复盘完成情况。
