# Expectant Father

准爸爸孕期行动手册。

本项目把孕期管理拆成几个可执行模块：按孕周了解当前阶段，按行动计划推进任务，按专题准备产检、爸爸任务、物资和办事事项。

默认供维护者家庭自用，地区为**浙江杭州**，主要医院为**浙江大学医学院附属妇产科医院**。详细边界见[使用范围](./docs/00-开始这里/使用范围.md)。

> 提醒：本项目用于家庭准备、记录和沟通，不替代医生、医院或当地官方要求。

## 个人资料仓库建议

本仓库只保存通用知识。当前孕周、具体预约、症状、检查摘要、办理状态和家庭调研记录，建议保存在独立、访问受控的私人资料仓库或其他私人记录工具中。

- 私人资料不要提交到本仓库。
- 使用 Git 时建议采用独立仓库、独立历史和受控远端；仓库名称与本地位置按使用环境自行配置。
- 可复制[个人资料仓库模板](./templates/个人资料仓库/README.md)和配套的 [`AGENTS.md`](./templates/个人资料仓库/AGENTS.md)，建立记录入口、隐私边界和 Git 维护规则。
- 处理个人资料前，应先读取实际私人资料仓库自己的维护约定；本仓库不记录其名称或位置。

## 推荐使用顺序

1. 从 [行动计划](./docs/02-行动计划/README.md) 找到当前孕周阶段。
2. 根据行动计划进入对应的 [产检指南](./docs/03-产检指南/README.md)。
3. 准爸爸同步查看 [爸爸指南](./docs/04-爸爸指南/README.md)。
4. 孕中晚期开始维护 [物资准备](./docs/05-物资准备/README.md)。
5. 出生前后持续维护 [办事指南](./docs/06-办事指南/README.md)。
6. 每周使用 [执行清单](./docs/07-执行清单/README.md) 复盘完成情况。
7. 需要长期追踪时复制 [记录模板](./docs/08-记录模板/README.md)。
