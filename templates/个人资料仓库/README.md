# 个人资料仓库模板

本模板用于建立独立、访问受控的家庭个人资料仓库，保存当前孕期节点、预约、症状、检查摘要、办理状态和家庭调研记录。它不要求固定的仓库名称、目录位置或与通用知识库的相对关系。

## 使用方法

1. 新建一个私有仓库或受控本地仓库。
2. 将本目录中的 `AGENTS.md` 和 `README.md` 复制到仓库根目录。
3. 按实际需要创建当前记录页和专题调研页，并在下方登记入口。
4. 在 `AGENTS.md` 中填写最近更新日期、通用知识库的发现方式、使用时区和推送策略；在私人记录中登记已采用的孕周基准日期、孕周和来源，没有精确基准时标记待确认。
5. 提交前确认远端访问权限，不要把私人仓库路径或家庭信息写回通用知识库。

## 记录入口

采用模板时用实际页面替换以下示例：

- 当前记录页：记录孕周、预约、症状、检查摘要、办理状态和下一步。
- 专题调研页：记录候选机构、报价、服务答复和家庭决定。

## 维护方式

- 有新的检查、预约或孕期进度时，更新当前记录页。
- 每条孕期记录按事项日期重算推算孕周，同时按当天日期更新当前概览；计算使用私人记录中已采用的精确基准和家庭配置时区。
- 记录事项实际发生日期，不额外标注数据何时补录、提供或确认；推算孕周保留计算截至日和基准来源。
- 有新的家庭调研信息或决定时，更新对应专题页。
- 通用医学知识、公共政策和可复用清单只链接到通用知识库，不在私人仓库重复维护。
- 原始报告、合同、证件、联系人、二维码和付款凭证不写入 Git 仓库。
- 具体更新触发、记录边界、提交和推送规则见同目录 `AGENTS.md`。

## 与通用知识库的关系

- 通用知识库只提供可复用知识、空白清单和本模板。
- 私人资料仓库只保存家庭个性化状态，名称和位置由使用者自行配置。
- Agent 通过当前工作区或用户提供的上下文定位另一个仓库，不依赖写死的相对路径。
