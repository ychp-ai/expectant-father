# 首次产检基础检查

## 建议时间

确认妊娠后尽早安排，并在孕 13 周前完成首次孕期健康管理和妊娠风险筛查。实际日期以医生、社区和建档医院安排为准。

## 这次要完成什么

- 确认孕周及医生采用的预产期。
- 建立孕产期保健记录并完成首次妊娠风险筛查。
- 了解孕妇的基础健康状况、妊娠相关风险和后续产检路径。
- 补充双方家族史、遗传病史及可能影响妊娠的暴露信息。

## 问诊与体格检查

首次规范产检通常包括以下信息和检查：

- 现病史、既往史、月经史、孕产史、避孕史、手术史、过敏史和用药情况。
- 孕妇个人史，以及夫妻双方家族史和遗传病史。
- 身高、体重、血压和全身体格检查。
- 按孕周及医疗机构流程进行产科或妇科检查。
- 对照妊娠风险筛查表完成首次风险筛查；筛查阳性时按要求接受上级机构评估和分级管理。

## 国家规范列明的基础化验

| 项目 | 主要用途 | 执行提醒 |
|---|---|---|
| 血常规 | 了解贫血等基础情况 | 结果交医生解读 |
| 血型 | 记录 ABO、Rh 等血型信息 | Rh 阴性等情况由医生制定后续方案 |
| 尿常规 | 了解尿液相关异常 | 按医院要求正确留取标本 |
| 阴道分泌物 | 评估生殖道相关情况 | 是否检查及采样方式以当次安排为准 |
| 肝功能 | 了解肝脏基础状态 | 是否空腹以医院通知为准 |
| 肾功能 | 了解肾脏基础状态 | 与既往病史一起评估 |
| 乙肝表面抗原 | 识别乙肝母婴传播风险 | 阳性时按专门规范管理 |
| 梅毒血清学检测 | 识别梅毒母婴传播风险 | 阳性或结果不明确时及时复诊 |
| 艾滋病病毒抗体检测 | 识别艾滋病母婴传播风险 | 依法保护隐私并按规范衔接服务 |

上述项目来自国家孕产期保健工作规范。具体项目组合、是否需要重复及报告名称可能因医院路径不同而变化。

## 建议或符合条件时检查

国家规范列举的建议检查包括血糖、宫颈脱落细胞学检查、沙眼衣原体及淋球菌检测、心电图等。临床还可能根据病史、症状、年龄、既往结果或当地流程安排甲状腺功能、丙肝等项目。

这些项目不是仅凭“常见”二字就人人都要做。检查前应确认：

- [ ] 为什么需要做。
- [ ] 是否有孕周、空腹或停用某些外用产品等准备要求。
- [ ] 结果异常后由哪个科室或机构衔接。
- [ ] 既往有效结果能否采用，避免无意义重复。

## 与产前筛查分开理解

首次基础检查用于了解孕妇健康和妊娠风险；NT、血清学筛查、孕妇外周血胎儿游离 DNA 筛查和产前诊断属于另一条出生缺陷防控路径。后者需要在有效孕周内接受知情说明，但不等于每个人必须把所有项目都做一遍。

详见[早期筛查](./早期筛查.md)和[中期筛查](./中期筛查.md)。

## 爸爸和家庭要做什么

- [ ] 爸爸补充本人及父系家族的遗传病、出生缺陷和重要疾病史。
- [ ] 双方共同核对长期用药、职业暴露及既往重要检查信息是否已告诉医生。
- [ ] 爸爸负责预约、交通、资料和报告归档，不替孕妇回答隐私问题或作医学决定。
- [ ] 家庭把下一次产检、限时筛查和社区随访加入日历。
- [ ] 感染或遗传风险需要检查爸爸时，按医生给出的机构和时限完成。

## 检查后

把实际项目、结果、风险分级、医生建议和下次预约记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告已经安全归档。
- [ ] 所有结果已经由医生查看，没有只凭参考范围自行判断。
- [ ] 待补项目、转诊或复查时间已经记录。
- [ ] 下一次产检及限时筛查已经加入家庭日历。
