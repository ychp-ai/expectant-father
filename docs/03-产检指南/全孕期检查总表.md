# 全孕期检查总表

先按孕周核对这一页，再打开具体检查的准备说明。本表覆盖常规产检、主要产前筛查及常见按风险追加项目；罕见疾病或复杂妊娠仍需医生制定个人方案，不能以“表中没有”判断无需检查。

## 如何区分项目

- **常规核对**：进入规范产检路径后应核对是否已经安排或有可用结果；检查频率由医生决定。
- **知情选择**：听取目标范围、局限、风险和后续路径说明后选择，不要求把所有筛查都做一遍。
- **按条件追加**：有病史、症状、异常结果、特定风险或医院路径时安排；“备选”不等于可以任意替代常规项目。

## 按孕周核对

| 阶段或窗口 | 常规核对 | 知情选择或按条件追加 | 家庭下一步 |
|---|---|---|---|
| 确认怀孕至首次规范产检 | 确认妊娠、孕周；超声了解妊娠位置、胎数及发育；首次问诊、体格检查和风险筛查 | 出血、腹痛或妊娠位置不明时由医生追加血液指标及超声；不默认人人连续测 hCG、孕酮 | 看[确认怀孕](./确认怀孕.md)，带既往报告 |
| 首次规范产检，尽量孕 13 周前 | 血常规、ABO/Rh 血型、尿常规、阴道分泌物、肝肾功能、乙肝表面抗原、梅毒和 HIV 检测；身高、体重、血压和妊娠风险评估 | 早期血糖评估；甲状腺功能、尿培养、铁蛋白、地贫等按病史或路径确认；心电图、宫颈及感染项目按医生安排 | 逐项对照[基础检查](./首次产检基础检查.md)，不要只记录“已抽血” |
| 孕 11～13+6 周 | NT 超声，核对孕周和早期超声所见；尽早评估子痫前期临床风险 | 早期血清学筛查通常孕 11～13+6 周；子痫前期联合预测检测按条件安排 | 看[早期筛查](./早期筛查.md)；NT 不替代遗传学筛查或诊断 |
| 孕 12～22+6 周／15～20+6 周 | 持续常规复诊，核对所有已选择筛查的报告和转诊 | 无创 DNA 通常孕 12～22+6 周；中期血清学筛查孕 15～20+6 周。按风险衔接遗传咨询、产前诊断 | 看[中期筛查](./中期筛查.md)；无创主要针对 21/18/13 三体，中唐还涉及开放性神经管缺陷风险，组合由医生说明 |
| 孕 20～24+6 周 | 中期胎儿结构超声；核对是否完成、显示不清部分是否需复查 | 胎儿心脏专科超声、宫颈长度及异常结构的进一步评估按条件安排 | 看[中期超声](./中期超声检查.md)；“四维”名称不等于确认已完成全部结构筛查 |
| 孕 24～28 周 | 按医生路径完成糖代谢筛查，常用 75 g OGTT；继续常规复诊及血尿检查 | 已确诊糖尿病等情况采用专门路径；贫血、Rh 阴性或抗体异常者另定复查方案 | 看[糖代谢检查](./糖代谢检查.md)，提前安排空腹及三次采血所需时间 |
| 孕 28～35 周 | 母体状态、胎动、胎儿生长、胎位评估；按国家规范孕晚期一次肝肾功能复查；血常规、尿常规按路径复查 | 生长超声、脐动脉等多普勒血流、NST 或其他胎儿监测按风险与医院安排 | 看[孕晚期评估](./孕晚期评估.md)；低风险孕妇不自行固定加做血流或胎监频率 |
| 孕 35～37 周前后 | 提前确认 GBS 筛查安排、报告和分娩期衔接；WHO 建议约孕 35～37 周普遍筛查 | 既往受影响新生儿、本孕期 GBS 尿培养阳性等情况主动告知医生，由医院确定是否采样和分娩期方案；感染风险变化时复查相应项目 | 看[分娩前筛查](./分娩前筛查.md)，当地采样窗口以医院路径为准 |
| 孕 37 周至分娩 | 按医生要求复诊，评估胎位、大小、羊水、胎盘及分娩条件；核对入院所需血尿、凝血及已有感染检测 | 超过预产期、胎动变化或妊娠并发症时增加监测、决定后续安排 | 看[临产前检查](./临产前检查.md)，每次明确下一次复评日期 |

## 每次产检都核对

- [ ] 已说明近期症状、用药和其他科室就诊情况，医生已动态评估风险。
- [ ] 已按孕周和医院路径评估体重、血压、宫高、胎心、胎位及必要的血尿项目。
- [ ] 前次报告已经给医生查看，待复查或转诊事项有明确下一步。
- [ ] 已确认下一次日期、院区、科室、报到点和准备要求。

详见[常规复诊与孕中晚期复查](./常规复诊与孕中晚期复查.md)。出现出血、持续腹痛、严重头痛、视物异常、疑似破水或胎动明显减少等情况时及时就医，不等待表中的窗口。

## 追加项目及个人进度怎么记

常见追加项目的适用条件见[条件性检查与产前诊断](./条件性检查与产前诊断.md)。

在私人记录中逐项记录：阶段、项目、是否适用、实际日期及孕周、预约、结果和医生查看状态、下一步。推荐使用“待确认／待安排／已预约／已检查待报告／待医生查看／已完成”；“不适用”须有医生或路径依据。窗口已过但没有记录，应先找报告核对，不直接判为漏做，也不自行决定补做已过时的筛查。
