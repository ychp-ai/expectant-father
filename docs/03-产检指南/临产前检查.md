# 临产前检查

## 建议时间

通常在孕 37 周后按医院安排增加产检频率，具体节奏以医生建议为准。

## 项目目的

- 持续评估孕妇血压、临产症状和其他健康变化。
- 评估胎动、胎心、胎位、胎儿生长及分娩条件。
- 确认分娩前检查是否齐全，以及入院条件和就医流程。
- 完成分娩前资料、物品和路线准备。

## 产检前

- [ ] 确认后续产检频率。
- [ ] 对照孕晚期检查确认血常规、尿常规、凝血及其他医院要求项目的安排。
- [ ] 确认 B 族链球菌或感染相关检查结果是否需要入院时主动告知。
- [ ] 准备孕期档案、证件和全部报告。
- [ ] 确认入院证件、医保和费用准备。
- [ ] 准备待产包和交通方案。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 主动反馈宫缩、见红、破水、胎动等情况。
- [ ] 完成医生安排的血压、宫高、胎心、胎位、超声或胎心监护等评估。
- [ ] 向医生确认何时需要去医院。
- [ ] 接近或超过预产期时，确认下一次复诊和进一步评估时间。
- [ ] 记录入院流程、联系电话和急诊入口。

## 产检后

把检查日期、孕周、医生建议、入院条件和下次就医安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 确认医院路线和停车方案。
- 检查待产包和证件。
- 记录医生关于入院时机的说明。
- 保持手机畅通并准备应急联系人。

## 常见问题

### 临近预产期还没发动怎么办？

按医生安排继续产检和观察，不要自行判断处理。

### 出现异常情况怎么办？

按医院提供的就医指引处理，必要时及时就医。
