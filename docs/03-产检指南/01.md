# 确认怀孕

## 建议时间

通常在月经推迟、早孕试纸阳性或出现早孕反应后开始确认。实际就诊时间请结合医生建议和个人情况安排。

## 项目目的

- 确认是否怀孕。
- 初步确认孕周范围。
- 记录末次月经日期，为后续推算预产期提供依据。
- 为首次产检和建档做准备。

## 预约与资料准备

- [ ] 记录末次月经第一天。
- [ ] 记录早孕试纸或验孕结果日期。
- [ ] 准备身份证、医保卡、既往检查报告。
- [ ] 整理既往病史、用药史、过敏史。
- [ ] 查询目标医院的首次产检和建档要求。

## 当天注意事项

- 按医院要求挂号和检查。
- 如有腹痛、明显出血、头晕等异常情况，及时向医生说明。
- 记录医生给出的复查时间和注意事项。

## 爸爸可以协助的事项

- 帮忙整理证件和既往报告。
- 查询医院预约流程和建档要求。
- 陪同就诊，记录医生建议。
- 建立孕期文件夹，保存后续报告。

## 常见问题

### 已经测出怀孕，是否马上去医院？

可以根据医院流程和医生建议安排确认检查。如果有不适或异常症状，应尽快就医。

### 末次月经日期不确定怎么办？

先记录大致范围，并在就诊时告诉医生，后续可结合检查结果校正孕周。
