# 首次产检与建档

## 建议时间

通常在孕早期完成首次产检，并根据医院和当地政策办理孕期档案。不同地区流程差异较大，请以目标医院要求为准。

## 项目目的

- 建立孕期档案。
- 明确后续产检医院和产检节奏。
- 完成基础信息登记和初始检查。
- 获取后续检查项目和时间安排。

## 预约与资料准备

- [ ] 确认目标医院是否需要提前预约。
- [ ] 准备身份证、医保卡、结婚证或其他当地要求材料。
- [ ] 准备既往检查报告、用药记录、过敏史记录。
- [ ] 记录末次月经日期和既往孕产史。
- [ ] 查询建档名额、建档时间、所需检查项目。

## 当天注意事项

- 预留足够时间办理挂号、缴费、检查和建档手续。
- 将医生说明的后续检查时间记录到日历。
- 如有既往疾病、长期用药或特殊情况，主动说明。

- 主管医生或科室：
- 下次产检时间：
- 已完成检查：
- 待补资料：

## 爸爸可以协助的事项

- 提前查询医院流程和停车路线。
- 携带并保管证件、报告、缴费凭证。
- 陪同排队和记录医生建议。
- 把后续检查时间同步到家庭日历。

## 常见问题

### 建档一定要在同一家医院生产吗？

多数情况下建议提前确认目标医院政策。是否能转院、如何转档，应咨询医院或当地社区卫生服务机构。

### 材料没带齐怎么办？

先完成可办理部分，并记录补交材料清单和截止时间。
