# 胎心监护

## 建议时间

通常在孕晚期按医院安排进行，具体开始时间和频率以医生建议为准。

## 项目目的

- 了解孕晚期胎儿状态。
- 记录检查结果和医生建议。
- 配合后续产检和临产前安排。

## 不要把社区免费服务等同于 5 次医院胎心监护

浙江基本公共服务口径为辖区常住孕产妇免费提供 5 次孕期健康管理：孕早期 1 次、孕中期 2 次、孕晚期 2 次。国家基本公共卫生服务记录中，第 2～5 次随访包含胎心率等常规产科检查记录；这通常是听取或测量胎心率，不等同于医院孕晚期使用监护设备完成并出具结果的胎心监护或无应激试验（NST）。

已确认的所属社区实际口径是，这 5 次免费健康管理只能在社区卫生院（社区卫生服务中心）完成。每次具体项目应按孕周和社区安排确认，不能理解成“保证免费做 5 次 NST”，也不能替代浙大妇院根据个人风险安排的产检、胎心监护或复查。

## 产检前

- [ ] 确认检查时间和地点。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期胎动情况。
- [ ] 预留等待时间。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 按医院要求完成检查。
- [ ] 如近期胎动明显异常，主动告知医生。
- [ ] 检查后确认是否需要复查或增加监测。

## 产检后

把检查日期、孕周、监护结果、医生建议和下次检查记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 陪同等待。
- 记录检查结果和医生建议。
- 设置后续产检提醒。
- 协助关注胎动记录。
