# 产检指南

本模块整理孕期常见产检项目的时间窗口、准备事项、当天注意事项和完成后记录。

> 提醒：具体检查安排、建档流程、检查项目选择和资料要求请以产科医生、医院和当地政策为准。本项目不提供诊断或治疗建议。

## 使用方式

- 先根据当前孕周查看对应的产检项目。
- 产检前查看“预约与资料准备”。
- 产检当天查看“当天注意事项”。
- 产检后把结果、医生建议和下次安排记录下来。
- 爸爸可重点负责预约、资料、交通、排队、报告归档和后续提醒。
