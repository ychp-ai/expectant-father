# 产检指南

本模块整理孕期常见产检项目的时间窗口、准备事项、当天注意事项和完成后记录。

> 提醒：具体检查安排、建档流程、检查项目选择和资料要求请以产科医生、医院和当地政策为准。本项目不提供诊断或治疗建议。

## 使用方式

- 先根据当前孕周查看对应的产检项目。
- 产检前查看“产检前”，确认预约、资料和问题清单。
- 产检当天按“产检当天”逐项执行并确认报告领取方式。
- 产检后在“产检后”保存原始报告、医生建议和下次安排。
- 爸爸可重点负责预约、资料、交通、排队、报告归档和后续提醒。
- 不知道整个阶段是否漏项时，先看[整个孕期三方检查与行动表](../00-开始这里/整个孕期三方检查与行动表.md)。
- 对“小卡”“大卡”“医院建档”含义不确定时，先看[小卡、大卡与医院系统产检](../06-办事指南/小卡大卡与医院系统产检.md)。
