# 早期筛查

## 建议时间

通常在孕早期指定时间窗口内完成，具体安排以医院和医生建议为准。

## 项目目的

- 了解孕早期发育情况。
- 为后续产检和筛查安排提供参考。
- 记录医生给出的下一步建议。

## 预约与资料准备

- [ ] 确认检查时间窗口。
- [ ] 提前预约。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 确认当天是否有特殊准备要求。

## 当天注意事项

- 按预约时间到达。
- 带齐既往报告。
- 检查后请医生说明结果和后续安排。

## 完成后记录

- 检查日期：
- 当日孕周：
- 结果摘要：
- 医生建议：
- 下次安排：

## 爸爸可以协助的事项

- 预约检查。
- 陪同就诊。
- 保存报告。
- 设置后续提醒。
