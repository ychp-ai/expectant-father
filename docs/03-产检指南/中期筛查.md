# 中期筛查

## 先分清两类安排

1. **染色体异常相关筛查路径**：血清学产前筛查或孕妇外周血胎儿游离 DNA 产前筛查等，具体选择和孕周由产检医生及有资质机构根据个人情况说明，不设一个适用于所有人的统一“16～20 周”窗口。
2. **中期超声筛查**：国家卫生健康委明确的服务孕周为 20～24+6 周，用于系统观察胎儿主要结构；它和血液筛查不是同一个项目，不能互相替代。

任何筛查都不等于产前诊断。筛查提示高风险、超声异常或有其他医学指征时，应由医生说明遗传咨询和进一步检查路径。

## 中唐为什么不能被简单理解为“无创的重复检查”

| 项目 | 现行参考孕周 | 主要目标 | 不能替代什么 |
|---|---|---|---|
| 早期血清学筛查 | 11～13+6 周 | 21 三体、18 三体风险 | 不能替代产前诊断或 NT 超声 |
| 中期血清学筛查（常称中唐） | 15～20+6 周 | 21 三体、18 三体和开放性神经管缺陷风险 | 不能作最终诊断，也不能替代中期超声 |
| 无创 DNA（NIPT） | 12～22+6 周 | 21、18、13 三体风险 | 不覆盖开放性神经管缺陷，不能替代产前诊断 |
| 中期超声筛查 | 20～24+6 周 | 常见严重胎儿结构异常 | 不能替代血清学或染色体相关检查 |

因此，“中唐有一个无创没有的指标”更准确的说法是：两者检测原理和目标范围不同，中期血清学筛查额外评估开放性神经管缺陷风险，而无创 DNA 的现行目标疾病是 21、18、13 三体。开放性神经管缺陷还需要结合中期超声等信息评估，不能只看一次血液筛查。

已做无创或已经选择产前诊断后，是否仍做中期血清学筛查，应向产检医生说明既往项目和结果，再确认是否需要利用其开放性神经管缺陷风险信息；不要自行重复叠加项目，也不要把任何筛查当成确诊。

## 杭州社区免费中期筛查

已确认的社区实际办理反馈是：建小卡后可在所属社区领取或登记一次免费中期血清学产前筛查服务，并且这项免费服务只能按该社区安排在社区卫生院（社区卫生服务中心）办理，不能默认拿到浙大妇院或其他医院免费使用。

这不是已由公开官方页面确认的杭州全市统一领券规则。领取时应当场确认适用人群、有效孕周、预约日期、是否在社区采血、检测机构、报告领取和异常转诊方式；筛查仍须知情选择，不能因为免费而跳过医生对高龄或其他风险因素的评估。具体办理见[杭州建小卡](../06-办事指南/杭州建小卡.md#建卡后核对社区免费服务)。

## 本阶段目标

- 确认此前已选择的筛查项目是否完成、报告由谁解读。
- 如尚未选择筛查路径，尽快让产检医生按当前孕周说明仍可考虑的项目，不照搬网络时间表。
- 提前预约 20～24+6 周中期超声筛查，核对院区和报到地点。

## 产检前

- [ ] 向医生确认本次是血清学筛查、游离 DNA 筛查、中期超声还是其他项目。
- [ ] 确认实施机构具备相应资质，并了解检测范围、局限和异常后的路径。
- [ ] 确认预约方式和检查地点。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 已确认是否需要特殊准备、预计耗时和报告领取方式。

## 产检当天

- [ ] 按要求完成检查。
- [ ] 如有多个项目，提前确认顺序和地点。
- [ ] 签署知情同意前再次核对项目名称和检测范围。
- [ ] 检查后记录结果领取方式和复诊安排。

## 产检后

把检查日期、筛查项目、结果、医生建议和后续安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 报告已交医生解读，没有根据“低风险”或“高风险”字样自行下结论。
- [ ] 需要遗传咨询、复查或产前诊断时，责任机构和时间要求已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 帮忙比较预约时间和路线。
- 保存项目说明、缴费记录和报告。
- 记录医生建议并同步家庭日历。
