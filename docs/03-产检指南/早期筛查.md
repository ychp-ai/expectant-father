# 早期筛查

## 先分清项目

- **孕早期 NT 超声筛查**：国家卫生健康委明确的服务孕周为 11～13+6 周，用超声测量胎儿颈项透明层等指标。
- **血清学产前筛查**：结合孕妇外周血指标、孕周等信息评估部分染色体异常风险，具体组合和时间由产检机构说明。
- **孕妇外周血胎儿游离 DNA 产前筛查**：常简称无创 DNA 或 NIPT，也属于筛查，应由具备相应资质的机构开展；是否适合、何时做和检测范围需知情选择。
- **产前诊断**：不是筛查的同义词。筛查提示高风险、超声异常或存在其他医学指征时，由医生说明是否需要遗传咨询和产前诊断。

筛查结果用于风险评估，不能仅凭“低风险”排除所有异常，也不能仅凭“高风险”自行认定诊断。

## 高龄孕妇怎么理解“早唐、无创和羊穿”

不能把这三项写成可以自行三选一的同类检查，也不宜把“高龄孕妇一律不做早唐”当成统一规则。

- **早期血清学筛查**：孕 11～13+6 周主要评估 21 三体和 18 三体风险。对于高龄等已有产前诊断指征的人群，它不能替代遗传咨询和产前诊断。
- **无创 DNA（NIPT）**：国家卫生健康委现行知情同意参考要点明确，适宜孕周为 12～22+6 周，主要筛查 21、18、13 三体；预产期年龄 ≥35 岁属于慎用人群。它仍是筛查，不是羊水穿刺等产前诊断的等价替代。
- **羊水穿刺等产前诊断**：属于侵入性诊断路径。是否需要、采用哪一种技术、何时实施以及相关风险，应由产前诊断机构在遗传咨询后说明，再由孕妇知情决定。
- **NT 超声**：与上述血液筛查或产前诊断不是一回事。无论最终选择无创还是产前诊断，都应向医生确认孕 11～13+6 周 NT 等早期超声筛查安排，不能默认被替代。

更稳妥的行动是：预产期年龄达到或超过 35 岁，或有异常孕产史、超声异常、家族遗传病等情况时，尽早预约遗传咨询或产前诊断门诊；不要只依据年龄、网络经验或一次筛查结果自行决定检查组合。

## 本阶段目标

- 在 11～13+6 周内完成或明确安排 NT 超声筛查。
- 听取医生对血清学筛查、游离 DNA 筛查等可选路径的说明。
- 了解检测范围、局限、费用、结果含义和异常后的下一步，再作知情选择。

## 产检前

- [ ] 根据医生确认的孕周核对 NT 是否处于 11～13+6 周窗口。
- [ ] 提前预约。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 确认当天是否有特殊准备要求。
- [ ] 询问本机构提供哪些筛查路径、由哪家有资质机构检测，以及是否需要另行预约。
- [ ] 把“检测什么、不能检出什么、结果多久出、异常后找谁”写入问题清单。

## 产检当天

- [ ] 按预约时间到达。
- [ ] 带齐既往报告。
- [ ] 签署知情同意前确认项目名称、检测范围和后续咨询渠道。
- [ ] 检查后请医生说明报告领取、结果解读和后续安排。

## 产检后

把检查日期、孕周、筛查结果、医生建议和下次安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 由医生解读筛查结果，未根据风险数字自行作诊断。
- [ ] 如需遗传咨询、进一步筛查或产前诊断，已记录责任机构和时间要求。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 预约检查。
- 陪同就诊。
- 保存报告。
- 设置后续提醒。
