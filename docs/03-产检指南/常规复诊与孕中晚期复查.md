# 常规复诊与孕中晚期复查

## 适用时间

完成首次产检后一直使用到临产。产检频率由孕周、妊娠风险分级、既往结果和医院路径共同决定；出现异常时不要等到预约日期。

## 每次复诊的基本框架

### 主动说明

- 近期不适、出血、腹痛、头痛、视物异常、水肿、胸闷或其他健康变化。
- 胎动出现及变化情况；孕晚期如胎动明显减少应及时联系医疗机构。
- 新增或停用的药物、补充剂及其他治疗。
- 近期急诊、其他科室就诊或检查情况。
- 情绪、睡眠和心理状态的持续变化。

### 医疗机构评估

- 查阅既往产检记录、化验和影像结果。
- 测量体重和血压。
- 按孕周检查宫高、胎心和胎位等。
- 动态筛查妊娠风险；健康状况发生变化时重新评估风险分级。
- 安排血常规、尿常规或其他需要复查的项目。

国家孕产期保健工作规范把血常规和尿常规列入复诊内容。实际是否每次都抽血或验尿，以及是否增加其他项目，以医院路径和个人情况为准。

## 按阶段核对

| 阶段 | 重点检查与复查 | 需要提前安排 |
|---|---|---|
| 孕 13～20 周 | 常规复诊；评估贫血等问题；完成产前筛查知情选择并衔接异常结果 | 中期超声和后续常规产检 |
| 孕 20～24+6 周 | 中期超声筛查；了解胎动出现时间；继续体重、血压、宫高、胎心及血尿等检查 | 糖代谢检查及必要复查 |
| 孕 24～28 周 | 妊娠期糖代谢筛查；继续常规复诊；按结果评估贫血、血压和其他风险 | 孕晚期复诊及医院要求的化验 |
| 孕 28～35 周 | 动态评估母体状态、胎儿生长、胎位和胎动；国家规范列有孕晚期一次肝肾功能复查 | 超声、胎心监护及其他项目以医生安排为准 |
| 孕 35～37 周前后 | 确认 B 族链球菌筛查路径；评估胎位、胎儿大小、羊水、胎盘及分娩条件 | 分娩前化验、入院评估和实际分娩院区 |
| 孕 37 周～分娩 | 按医生安排增加复诊；持续评估母胎状态和临产情况；超过预产期按时复评 | 每次下一步安排和发动时就医路径 |

## 符合条件时增加的项目

| 情况 | 可能增加的评估 | 注意 |
|---|---|---|
| Rh 阴性或存在血型相关风险 | 抗体监测及相关处理 | 由医生结合孕周和既往史安排 |
| 贫血或血液指标异常 | 血常规、铁相关检查或其他评估 | 不自行补铁或调整剂量 |
| 高血压、尿蛋白或相关症状 | 增加血压、尿液、血液及胎儿监测 | 出现危险信号及时就医 |
| 糖代谢异常 | 血糖监测、营养评估和胎儿生长监测 | 按医生方案执行 |
| 胎儿生长、胎盘、羊水或胎动异常 | 增加超声、胎心监护或其他评估 | 频率由医生确定 |
| 遗传风险或产前筛查异常 | 遗传咨询、进一步筛查或产前诊断 | 到有相应资质的机构 |
| 感染风险或首次结果异常 | 复查或补充感染相关检测 | 配偶是否检测由医生按规范判断 |
| 持续焦虑、抑郁、失眠或功能受影响 | 孕产期心理健康筛查和转诊 | 不把明显症状简单归因于“孕期正常” |

## 哪些做法需要避免

- 不根据网上固定表格自行决定抽血、超声或胎心监护频率。
- 不把所有常见项目都理解为人人必做。
- 不用家庭胎心设备代替胎动观察、产检或医疗机构的胎心监护。
- 不自行解释筛查、化验和超声结果，也不根据单个数值调整药物。
- 不等到下一次预约才处理出血、持续腹痛、严重头痛、视物异常、破水或胎动明显减少等情况。

## 爸爸和家庭固定动作

- [ ] 产检前确认日期、院区、科室、空腹或其他准备要求。
- [ ] 带齐孕期档案和此前报告，准备本次问题清单。
- [ ] 产检后记录医生解释、待复查事项和下一次日期。
- [ ] 家庭每周核对一次预约、报告、单位手续和待产事项。
- [ ] 关注孕妇情绪、睡眠和家庭压力，需要时支持其获得专业帮助。

具体预约、检查结果、风险分级和医生建议只记录在个人资料仓库的当前记录页。
