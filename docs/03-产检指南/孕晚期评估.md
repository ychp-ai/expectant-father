# 孕晚期评估

## 建议时间

通常在孕晚期按医院安排进行，具体项目和频率以医生建议为准。

## 项目目的

- 动态评估孕妇健康、胎儿生长、胎位、胎动和妊娠风险。
- 记录是否需要复查或调整产检频率。
- 为临产前准备提供参考。

## 常见评估框架

- 询问近期不适、胎动和用药变化。
- 测量体重、血压，并按孕周检查宫高、胎心和胎位等。
- 按医院安排复查血常规、尿常规或其他化验。
- 国家孕产期保健工作规范列有孕晚期一次肝功能、肾功能复查。
- 孕 36 周前后可评估胎儿大小、胎位和分娩条件；是否进行超声、胎心监护及具体时间由医生和医院路径确定。
- 健康状况变化时重新进行妊娠风险评估和分级。

## 产检前

- [ ] 确认检查时间。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期体重、血压、胎动等信息。
- [ ] 整理想咨询医生的问题。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 带齐近期报告。
- [ ] 主动反馈近期不适和胎动变化。
- [ ] 确认本阶段血尿、肝肾功能或其他复查是否已安排。
- [ ] 询问胎儿生长、胎位、羊水、胎盘和分娩条件是否需要进一步评估。
- [ ] 记录医生给出的后续安排。

## 产检后

把实际检查项目、结果、风险分级、医生建议和下次预约记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 整理近期记录。
- 陪同就诊。
- 记录医生建议。
- 更新待产准备清单。
