# 条件性检查与产前诊断

先向医生核对“为什么做、何时做、已有结果能否采用、结果出来后找谁”。本页覆盖常见追加检查，不能穷尽所有疾病的检查路径，也不把追加项目都写成人人必做。

## 母体风险及追加化验

| 项目 | 何时核对及常见适用条件 | 行动与边界 |
|---|---|---|
| 子痫前期早期风险评估 | 首次产检尽早说明既往子痫前期、慢性高血压、肾病、自身免疫病、糖尿病等；孕 11～13+6 周是早期预测的重要窗口 | 先做临床风险评估；有条件时结合平均动脉压、子宫动脉搏动指数、胎盘生长因子（PlGF）等联合预测。单个指标不能独立排除风险；后续继续血压及症状监测，预防用药由医生决定（CN-PE-001） |
| 尿培养／无症状菌尿评估 | 首次产检询问是否纳入本院路径；有尿路症状、既往感染或相关风险时及时询问 | WHO 推荐中段尿培养用于诊断无症状菌尿；尿常规或“已尿检”不能直接视为已经培养。留样及是否复查按医嘱，不自行使用抗生素（WHO-ANC-001） |
| 甲状腺功能 | 孕早期询问本院路径；既往甲状腺病、相关症状或既往异常时主动说明 | 项目及复查时间待医生确定，不凭本表自行安排或解读；与其他首次产检追加项目一并核对，见[基础检查](./首次产检基础检查.md) |
| 铁蛋白等贫血原因检查 | 血常规异常、既往贫血或医生需要鉴别原因时 | 贫血不都由缺铁引起；铁相关检查、血红蛋白分析等按原因选择，补充剂按处方，不根据本表自行调整（CN-PBM-001、CN-THAL-001） |
| 地中海贫血及其他遗传病携带者评估 | 尽量孕前或孕早期；结合双方既往筛查、血液指标、家族史及地区人群风险 | 地贫可采用血常规、血红蛋白分析和基因检测等分层评估；一方携带时需按医生意见检查另一方。夫妻组合风险需遗传咨询，无创常见三体筛查不能替代地贫评估（CN-THAL-001） |
| 红细胞抗体检查 | 首次血型结果核对后，Rh 阴性、抗体异常或相关孕产史者制定方案 | 确认是否已做抗体筛查及何时复查；ABO/Rh 分型不等于抗体筛查。预防或处理由医生安排（CN-NHC-001、NICE-ANC-001） |
| 血压／尿蛋白及肝肾、血小板等 | 高血压、相关症状或医生怀疑并发症时 | 医生决定尿蛋白定量、血液检查及母胎监测；严重头痛、视物异常等应及时就医（CN-NHC-001） |
| 感染及症状相关检查 | 感染暴露、发热、皮疹、瘙痒或既往异常时 | 按具体症状和风险选择项目；不把 TORCH 等整套检测一概列为所有孕妇必做。三项母婴传播感染检测仍按[基础检查](./首次产检基础检查.md)和[分娩前筛查](./分娩前筛查.md)核对；严重或手掌、足底瘙痒及时咨询，不能仅按普通皮肤问题处理（CN-NHC-001、CN-PMTCT-001、NHS-ITCH-001） |
| 心理健康及血栓风险评估 | 首次产检及健康状况变化时；持续情绪困扰、住院、既往血栓或相关病史需说明 | 筛查、专科转诊及症状相关检查按医生决定；单侧腿痛、胸痛或气短不能只靠网上表格判断（NICE-ANC-001） |

## 胎儿、胎盘及早产风险

| 项目 | 常见适用条件／参考窗口 | 家庭要问什么 |
|---|---|---|
| 胎儿心脏专科超声 | 常规超声怀疑心脏异常，或母体、胎儿、家族风险需专科评估；ASE 给出的完整经腹检查最佳窗口为孕 18～22 周，具体日期及复查按专科安排 | 已完成的结构超声是否足够？为什么转诊？不是所有正常结构筛查之后都必加做一次（ASE-FE-001） |
| 经阴道超声宫颈长度 | 既往自发性早产、中期流产、宫颈损伤／手术或其他早产风险；有症状时另行及时评估。NICE 风险路径包含孕 16～24 周测量 | 是一次评估还是需要随访？本院测量方式及后续安排是什么？不把这个窗口写成全国所有孕妇统一必做（NICE-PTB-001） |
| 生长超声、胎盘／羊水复查 | 生长疑虑、胎盘位置异常、羊水异常、多胎或其他并发症 | 明确复查目的和间隔；结构筛查不能代替后续生长及胎盘评估（CN-NHC-001） |
| 多普勒血流 | 怀疑生长受限、胎盘功能问题或医生指定风险 | 子宫动脉、脐动脉、大脑中动脉检查的目的不同；不要求所有低风险孕妇每次加做（WHO-ANC-001） |
| NST／其他胎儿监测、生物物理评分等 | 胎动变化、妊娠并发症、生长或羊水异常、超过预产期等由医生评估；也可能按本院孕晚期路径安排 | 何时开始、频率、结果后是否要追加评估？常规听胎心与 NST 不同，详见[胎心监护](./胎心监护.md)（CN-NHC-001、WHO-ANC-001） |

## 产前诊断：取样方式和检测技术分开问

筛查提示风险、超声异常、遗传病家族史、既往相关不良孕产史或年龄等情况，应到有资质的产前诊断机构接受咨询。高龄孕妇不能仅凭“无创低风险”自动关闭咨询路径，详见[早期筛查](./早期筛查.md)（CN-PND-001、CN-PNS-001）。

| 层面 | 常见名称 | 需要核对 |
|---|---|---|
| 取样 | 绒毛膜穿刺／绒毛取样（CVS）、羊膜腔穿刺（羊穿）、脐静脉穿刺／脐血取样 | 为什么选该方式？可用孕周、操作风险、准备、术后观察和急诊指征？不同取样方式不是随意互换的检查套餐（CN-PND-002） |
| 标本上的检测 | 染色体核型、染色体微阵列（CMA）／拷贝数变异检测、针对性基因检测等 | 能发现什么、不能发现什么、是否可能出现意义不明结果、是否需要父母标本、报告时间和遗传咨询安排？羊穿是取样操作，不等于所有遗传病都查过（CN-PND-002、CN-THAL-001） |

取样孕周和检测组合须由机构按适应证说明，不在家庭手册中给出自选方案；筛查高风险不等于确诊，低风险也不排除所有异常。扩展无创或广泛基因检测不能直接当作产前诊断的替代项。

## 个人记录字段

- 是否适用：待医生确认／医生已说明适用／医生已说明无需本次检查（记录理由）。
- 执行状态：待安排、已预约、已检查待报告、待医生查看、已完成。
- 留下实际日期、推算孕周、报告位置、医生说明及下一步；窗口已过但记录不明时先核对报告。
