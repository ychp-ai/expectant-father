# 孕晚期感染筛查与分娩前检查

## 建议时间

通常从孕 33～36 周开始确认，并在孕晚期后段按医院和医生安排完成。不同项目的时间和适用人群不同。

## 项目目的

- 补齐分娩前需要的母体和胎儿评估。
- 确认本院是否安排 B 族链球菌等孕晚期感染筛查。
- 发现首次产检遗漏、感染风险变化或其他异常时及时补查。
- 为住院分娩、麻醉和紧急处置准备必要资料。

## B 族链球菌筛查

B 族链球菌筛查常在孕晚期进行，但中国国家孕产期保健工作规范没有为所有医院规定统一的普遍筛查窗口，国内外指南及医院路径也可能不同。因此本项目不把某个固定孕周写成杭州所有孕妇的统一强制要求。

孕 33～36 周应主动询问：

- [ ] 浙大妇院是否为本人安排 B 族链球菌筛查。
- [ ] 检查孕周、采样部位和检查前注意事项。
- [ ] 结果由谁解释，阳性时分娩入院需要主动告诉谁。
- [ ] 哪些情况不需要重复采样，哪些情况需要按医生安排处理。

筛查阳性不等于现在就应自行口服或外用抗生素。用药时机、药物选择和分娩期处理必须由医生决定。

## 孕晚期可能补充或复查的感染项目

- 首次产检应尽早完成艾滋病、梅毒和乙肝检测。
- 感染风险较高、首次结果异常或医生认为有必要时，可能在孕晚期复查或增加项目。
- 分娩前仍不能明确感染状态时，医疗机构会按相关规范尽快检测和处理。
- 孕妇发现相关感染时，爸爸或性伴是否需要检测和处理，由医生或专门机构按规范安排。

这些结果属于敏感医疗信息，只记录在私人位置。

## 分娩前常见检查框架

按国家孕产期保健工作规范，分娩接诊时的基础辅助检查包括血常规、尿常规和凝血功能；孕期未完成血型、肝肾功能、乙肝表面抗原、梅毒检测者需要补齐，未做艾滋病检测者应尽快检测。医院还可能根据麻醉、手术、妊娠风险或既往结果增加其他项目。

是否在门诊提前完成、入院后完成或采用既往结果，以浙大妇院当次安排为准。

## 产检前

- [ ] 确认检查时间。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期身体情况。
- [ ] 对照首次基础检查确认血型、肝肾功能及三项母婴传播感染检测是否已有有效结果。
- [ ] 询问血常规、尿常规、凝血及医院要求的其他项目何时完成。
- [ ] 确认是否安排 B 族链球菌筛查及其准备要求。
- [ ] 确认报告领取方式。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 按医院流程完成检查。
- [ ] 主动告知药物过敏、感染风险、既往异常结果和当前用药。
- [ ] 检查后确认后续安排。
- [ ] 保存报告。

## 产检后

把实际检查项目、结果、感染状态、医生建议和后续安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 陪同就诊。
- 整理报告。
- 医生要求爸爸接受感染相关检测时，按指定机构和时限完成。
- 确认分娩入院时需要主动告知的检查结果，但尊重孕妇医疗隐私。
- 更新入院资料清单。
- 设置后续提醒。
