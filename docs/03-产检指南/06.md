# 糖代谢检查

## 建议时间

通常在孕 24～28 周左右按医院安排完成，具体时间和准备要求以医生说明为准。

## 项目目的

- 了解孕期糖代谢相关情况。
- 根据结果确认后续饮食、运动、复查或管理建议。
- 为孕晚期产检安排提供参考。

## 预约与资料准备

- [ ] 确认检查时间和地点。
- [ ] 询问是否需要空腹或其他准备。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 预留较长检查时间。

## 当天注意事项

- 按医院要求完成准备。
- 检查期间按流程等待和抽血。
- 如有不适，及时告知医护人员。

## 完成后记录

- 检查日期：
- 当日孕周：
- 结果摘要：
- 医生建议：
- 后续安排：

## 爸爸可以协助的事项

- 提醒检查前准备要求。
- 陪同等待。
- 准备水、纸巾和轻便物品。
- 保存报告并记录医生建议。
