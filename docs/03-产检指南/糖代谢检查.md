# 糖代谢检查

## 建议时间

通常在孕 24～28 周左右按医院安排完成，具体时间和准备要求以医生说明为准。

## 项目目的

- 了解孕期糖代谢相关情况。
- 根据结果确认后续饮食、运动、复查或管理建议。
- 为孕晚期产检安排提供参考。

## 产检前

- [ ] 确认检查时间和地点。
- [ ] 询问是否需要空腹或其他准备。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 预留较长检查时间。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 按医院要求完成准备。
- [ ] 检查期间按流程等待和抽血。
- [ ] 如有不适，及时告知医护人员。

## 产检后

把检查日期、孕周、检查结果、医生建议和后续安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 提醒检查前准备要求。
- 陪同等待。
- 准备水、纸巾和轻便物品。
- 保存报告并记录医生建议。
