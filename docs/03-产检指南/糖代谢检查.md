# 糖代谢检查

## 建议时间

通常在孕 24～28 周按医院安排完成。常用检查为 **75 g 口服葡萄糖耐量试验（OGTT，俗称糖耐）**，包括空腹、服糖后 1 小时和 2 小时三次静脉采血（CN-GDM-001）。

## 早期评估与特殊路径

- 首次产检核对是否已按医生要求评估血糖；既往糖尿病、妊娠期糖尿病、胰岛素抵抗或已有异常结果时主动说明。
- 医生决定是否提前检查、复查或进入专门管理路径；已经确诊糖尿病者不自行再安排普通筛查。
- 早期一次血糖结果或动态血糖仪记录，不自动等于已完成孕 24～28 周的 OGTT；由医生确认能否采用及后续安排。

## 项目目的

- 了解孕期糖代谢相关情况。
- 根据结果确认后续饮食、运动、复查或管理建议。
- 为孕晚期产检安排提供参考。

## 产检前

- [ ] 确认检查时间和地点。
- [ ] 核对空腹要求、前几日饮食与活动要求、当日药物安排；不自行停药、刻意少吃或改变饮食来影响结果。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 确认糖液领取或配制方式、服糖计时规则，以及三次采血地点；预留至少覆盖服糖后 2 小时及排队的时间。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 按医院要求完成准备。
- [ ] 按医院规定完成空腹采血、服糖和两次定时采血；检查期间饮食、饮水及活动按现场要求执行。
- [ ] 如有不适，及时告知医护人员。
- [ ] 如呕吐、漏抽或错过采血时间，及时告知工作人员，由医院决定本次结果是否有效及如何处理。

## 产检后

把检查日期、孕周、检查结果、医生建议和后续安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 提醒检查前准备要求。
- 陪同等待。
- 准备水、纸巾和轻便物品。
- 保存报告并记录医生建议。
