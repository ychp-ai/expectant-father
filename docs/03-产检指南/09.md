# 分娩前筛查

## 建议时间

通常在孕晚期后段按医院安排完成。

## 项目目的

- 完成分娩前相关检查。
- 记录结果和医生建议。
- 更新入院准备事项。

## 预约与资料准备

- [ ] 确认检查时间。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期身体情况。
- [ ] 确认报告领取方式。

## 当天注意事项

- 按医院流程完成检查。
- 检查后确认后续安排。
- 保存报告。

- 结果摘要：
- 医生建议：
- 后续安排：

## 爸爸可以协助的事项

- 陪同就诊。
- 整理报告。
- 更新入院资料清单。
- 设置后续提醒。
