# 中期超声检查

## 建议时间

通常在孕中期按医院安排完成，具体时间以医生建议为准。

## 项目目的

- 了解孕中期发育情况。
- 保存检查报告。
- 确认后续产检和复查安排。

## 预约与资料准备

- [ ] 提前预约。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 确认检查地点和报到时间。
- [ ] 预留足够检查时间。

## 当天注意事项

- 按预约时间到达。
- 带齐既往资料。
- 检查后请医生说明后续安排。

## 完成后记录

- 检查日期：
- 当日孕周：
- 结果摘要：
- 医生建议：
- 下次安排：

## 爸爸可以协助的事项

- 负责预约和路线。
- 陪同检查。
- 保存报告。
- 设置后续提醒。
