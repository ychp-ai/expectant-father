# 胎心监护

## 建议时间

通常在孕晚期按医院安排进行，具体开始时间和频率以医生建议为准。

## 项目目的

- 了解孕晚期胎儿状态。
- 记录检查结果和医生建议。
- 配合后续产检和临产前安排。

## 预约与资料准备

- [ ] 确认检查时间和地点。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期胎动情况。
- [ ] 预留等待时间。

## 当天注意事项

- 按医院要求完成检查。
- 如近期胎动明显异常，主动告知医生。
- 检查后确认是否需要复查或增加监测。

- 结果摘要：
- 医生建议：
- 下次检查：

## 爸爸可以协助的事项

- 陪同等待。
- 记录检查结果和医生建议。
- 设置后续产检提醒。
- 协助关注胎动记录。
