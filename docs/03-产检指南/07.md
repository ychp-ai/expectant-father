# 孕晚期评估

## 建议时间

通常在孕晚期按医院安排进行，具体项目和频率以医生建议为准。

## 项目目的

- 了解孕晚期发育和母体状态。
- 记录是否需要复查或调整产检频率。
- 为临产前准备提供参考。

## 预约与资料准备

- [ ] 确认检查时间。
- [ ] 准备孕期档案和既往报告。
- [ ] 记录近期体重、血压、胎动等信息。
- [ ] 整理想咨询医生的问题。

## 当天注意事项

- 带齐近期报告。
- 主动反馈近期不适和胎动变化。
- 记录医生给出的后续安排。

## 完成后记录

- 检查日期：
- 当日孕周：
- 结果摘要：
- 医生建议：
- 下次产检时间：

## 爸爸可以协助的事项

- 整理近期记录。
- 陪同就诊。
- 记录医生建议。
- 更新待产准备清单。
