# 中期筛查

## 建议时间

通常在孕中期按医院安排完成。不同医院的项目名称、时间窗口和预约方式可能不同。

## 项目目的

- 了解孕中期相关筛查安排。
- 根据医生建议选择合适的检查项目。
- 保存结果并确认后续产检计划。

## 预约与资料准备

- [ ] 咨询医生可选项目和适用时间。
- [ ] 记录医生建议。
- [ ] 确认预约方式和检查地点。
- [ ] 准备孕期档案、证件和既往报告。

## 当天注意事项

- 按要求完成检查。
- 如有多个项目，提前确认顺序和地点。
- 检查后记录结果领取方式和复诊安排。

## 完成后记录

- 检查日期：
- 已完成项目：
- 结果摘要：
- 医生建议：
- 后续安排：

## 爸爸可以协助的事项

- 帮忙比较预约时间和路线。
- 保存项目说明、缴费记录和报告。
- 记录医生建议并同步家庭日历。
