# 中期超声检查

## 建议时间

通常在孕中期按医院安排完成，具体时间以医生建议为准。

## 项目目的

- 了解孕中期发育情况。
- 保存检查报告。
- 确认后续产检和复查安排。

## 产检前

- [ ] 提前预约。
- [ ] 准备孕期档案、证件和既往报告。
- [ ] 确认检查地点和报到时间。
- [ ] 预留足够检查时间。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 按预约时间到达。
- [ ] 带齐既往资料。
- [ ] 检查后请医生说明后续安排。

## 产检后

把检查日期、孕周、超声结果、医生建议和下次安排记录到个人资料仓库的当前记录页，不要填写在本通用页面。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 负责预约和路线。
- 陪同检查。
- 保存报告。
- 设置后续提醒。
