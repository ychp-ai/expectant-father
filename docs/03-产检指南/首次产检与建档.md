# 首次产检与建档

## 建议时间

通常在孕早期完成首次规范产检，并根据社区和主要产检医院分别建立孕期记录。浙大妇院公开建议孕 13 周前尽早建立围产保健手册并接受系统产检；具体科室、院区、材料和预约方式以医院当次要求为准。

## 项目目的

- 建立社区孕产妇健康记录和医院系统产检记录，并分清各自完成标志。
- 明确后续产检医院和产检节奏。
- 完成首次妊娠风险筛查、基础信息登记和初始检查。
- 获取后续检查项目和时间安排。

首次产检的问诊、体格检查和基础化验详见[首次产检基础检查](./首次产检基础检查.md)。医院系统产检、社区建小卡、普通门诊档案、生育登记和分娩住院登记不是同一个事项，详见[小卡、大卡与医院系统产检](../06-办事指南/小卡大卡与医院系统产检.md)。

## 产检前

- [ ] 确认目标医院是否需要提前预约。
- [ ] 准备孕妇身份证件、医保凭证、社区手册和已有报告；结婚证、户口本等只在医院当次明确要求时携带。
- [ ] 准备既往检查报告、用药记录、过敏史记录。
- [ ] 记录末次月经日期和既往孕产史。
- [ ] 整理夫妻双方家族史、遗传病史和可能影响妊娠的暴露信息。
- [ ] 查询建立围产保健或系统产检记录的科室、院区、时间、名额和所需检查项目。

- [ ] 已确认是否需要预约、特殊准备、预计耗时和报告领取方式。
- [ ] 已把需要咨询的问题写入记录。

## 产检当天

- [ ] 预留足够时间办理挂号、缴费、检查和建档手续。
- [ ] 确认妊娠风险筛查结果是否需要上级机构评估或转诊。
- [ ] 将医生说明的后续检查时间记录到日历。
- [ ] 如有既往疾病、长期用药或特殊情况，主动说明。
- [ ] 确认本次完成的是普通门诊就诊、首次规范产检还是医院系统产检记录，不能只记录“已建档”。

## 产检后

把建档医院和日期、科室、下次产检时间、已完成检查及待补资料填写到个人资料仓库的当前记录页，不要在本通用页面记录具体医生、预约或检查结果。

- [ ] 原始报告或检查凭证已归档。
- [ ] 医生建议、待复查事项和下次时间已记录。
- [ ] 下次安排已加入家庭日历。
- [ ] 已确认系统产检记录的后续预约入口，以及社区记录和外院报告怎样衔接。

> 可复制使用[产检记录模板](../08-记录模板/产检记录.md)。

## 爸爸可以协助的事项

- 提前查询医院流程和停车路线。
- 携带并保管证件、报告、缴费凭证。
- 陪同排队和记录医生建议。
- 把后续检查时间同步到家庭日历。

## 常见问题

### 建档一定要在同一家医院生产吗？

不能从“已经系统产检”直接推定必须或一定能在同一家医院分娩。是否接收转院、外院报告如何衔接、分娩院区和住院登记怎样办理，应分别咨询原医院、新医院和社区。

### 材料没带齐怎么办？

先完成可办理部分，并记录补交材料清单和截止时间。
