# 出生后爸爸任务

## 阶段重点

宝宝出生后，爸爸需要同时支持妈妈恢复、照顾新生儿、处理证件和家庭协调。

## 你需要主动承担

- [ ] 保存出生相关资料和医院文件。
- [ ] 记录宝宝出生时间、体重、身长等信息。
- [ ] 协助妈妈休息、进食、补水和恢复。
- [ ] 学习换尿布、拍嗝、安抚和基础清洁。
- [ ] 跟进出生证明、医保、户口等后续事项。
- [ ] 管理探视频率，减少妈妈和宝宝被打扰。

## 医院期间任务

- 负责证件、缴费、报告和出院材料。
- 记录医生和护士给出的护理提醒。
- 协助妈妈下床、取物、吃饭和休息。
- 学习基础照护动作，不只旁观。

## 回家后任务

- 安排家务、餐食、清洁和采购。
- 记录宝宝喂养、睡眠、排便和异常情况。
- 关注妈妈情绪和身体恢复。
- 处理亲友沟通，避免过度打扰。

- 新生儿医保：
- 户口：
- 疫苗接种本：
- 商业保险或其他事项：

## 沟通建议

- 不把照护说成“帮忙”，这是共同责任。
- 不用“你怎么还不会”评价妈妈。
- 家人意见不一致时，先保护妈妈休息和宝宝需求。
- 不确定事项及时问医生或专业人员。

## 每日固定动作

- 确认妈妈休息和饮食。
- 参与至少一项宝宝照护。
- 记录宝宝基础情况。
- 整理当天待办和次日安排。
