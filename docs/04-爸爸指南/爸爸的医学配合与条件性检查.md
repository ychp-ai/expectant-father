# 爸爸的医学配合与条件性检查

## 先说结论

伴侣怀孕后，爸爸没有一套适用于所有人的“孕期必做体检套餐”。爸爸的医学责任主要是如实提供本人和家族信息，并在遗传风险、感染风险或医生明确要求时及时接受检查。

不要因为担心漏项而自行购买男性生育全套、精液检查、大范围基因检测或其他套餐。

## 首次产检前提供的信息

- [ ] 本人重要疾病史、手术史和当前长期用药。
- [ ] 本人及父系家族中的遗传病、出生缺陷、智力或发育异常情况。
- [ ] 夫妻双方既往不良孕产史及医生曾经提出的遗传风险。
- [ ] 可能影响家庭健康的职业、化学、生物或放射暴露。
- [ ] 可能影响孕妇的传染病、性传播感染史或近期高风险暴露。

这些内容应在就诊时如实告诉医生。具体个人信息和结果只放在个人资料仓库的当前记录页，不要写入通用仓库。

## 符合条件时接受检查

### 遗传与携带者风险

以下情况可能需要爸爸接受遗传咨询或检测：

- 孕妇被发现为某种遗传病携带者，需要结合爸爸结果判断胎儿风险。
- 双方家族存在相同或相关遗传病、出生缺陷或不明原因早逝。
- 既往有反复不良孕产史，或本次筛查、超声提示需要进一步评估。
- 产科或有资质的遗传咨询、产前诊断机构提出明确要求。

检查项目可能涉及血液学、携带者检测、染色体或其他遗传检测，但没有适用于所有家庭的统一组合。

### 感染相关风险

孕妇首次产检应尽早接受艾滋病、梅毒和乙肝检测。孕妇发现感染，或双方存在相关暴露风险时，爸爸或性伴应按医生、疾控或专门机构要求接受检测、咨询和必要处理。

- 不隐瞒可能影响孕妇和胎儿的感染或暴露信息。
- 不自行购买或共用药物。
- 不因担心隐私而延误正规检测；医疗机构应依法保护个人隐私。
- 结果和后续方案只由专业机构解释。

### 爸爸本人出现传染性疾病

爸爸出现发热、呼吸道传染病、出疹性疾病或其他可能传给孕妇的情况时，应及时就医并按医疗建议减少家庭传播。是否需要隔离、检测或调整接触方式，由接诊医生判断。

## 通常不需要因为怀孕自动进行

- 男性生育全套或精液检查。
- 没有家族史、筛查异常或医生建议时的大范围基因检测。
- 仅为了预测胎儿血型而进行的检查。
- 与孕妇检查完全相同的一整套抽血化验。
- 根据网络清单自行重复艾滋病、梅毒、乙肝或其他感染检测。

爸爸仍应按年龄、职业和自身疾病情况接受常规健康管理，但这与伴侣孕期产检不是同一件事。

## 爸爸在每次产检中的职责

- [ ] 产检前核对预约、院区、科室和准备要求。
- [ ] 提醒双方把新增病史、用药、暴露或家族信息告诉医生。
- [ ] 共同参与产前筛查知情沟通，但尊重孕妇本人意愿和医疗隐私。
- [ ] 医生要求检查爸爸时，确认项目名称、目的、时限和报告交给谁。
- [ ] 产检后整理报告、复查要求和下一次安排。
- [ ] 关注孕妇情绪和家庭压力，不用“都是正常的”敷衍持续异常。
