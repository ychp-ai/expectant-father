# 爸爸指南

本模块面向准爸爸，整理孕期不同阶段可以主动承担的任务。

重点不是替代医生或妈妈做决定，而是把“支持、记录、准备、沟通、执行”具体化。

## 使用方式

- 按当前孕周阶段查看对应任务。
- 每周和妈妈一起确认下一步安排。
- 把产检、证件、报告、物资和待办事项统一记录。
- 遇到不确定情况，以医生、医院和当地政策要求为准。

## 爸爸任务原则

- 主动记录，不只口头答应。
- 主动预约，不把流程压力留给妈妈。
- 主动沟通，不用“你决定吧”代替参与。
- 主动学习，不等问题出现才查资料。
- 主动兜底，把路线、证件、报告和应急联系人准备好。
