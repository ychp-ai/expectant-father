# 孕晚期爸爸任务

## 阶段重点

孕晚期的重点是减少临时决策：待产包、证件、路线、入院流程、应急联系人都要提前准备好。

## 你需要主动承担

- [ ] 检查待产包是否齐全。
- [ ] 准备证件、医保、产检资料和报告。
- [ ] 确认医院路线、停车点、急诊入口和夜间方案。
- [ ] 保存医院电话、家人电话和应急联系人。
- [ ] 跟进孕晚期产检和监测安排。
- [ ] 协助记录胎动、宫缩和其他需要反馈医生的信息。

## 入院准备

- 证件资料放在固定位置。
- 待产包按妈妈用品、宝宝用品、证件资料分类。
- 手机保持电量充足，准备充电器和移动电源。
- 确认谁负责送医、谁负责照看家里、谁负责通知家人。

## 家庭支持

- 主动承担家务和采购。
- 减少让妈妈弯腰、久站和搬重物。
- 陪同散步或活动时注意节奏。
- 产检后主动复盘下一步安排。

## 沟通建议

- 不催促、不制造焦虑。
- 不用“快生了就别想太多”敷衍情绪。
- 共同确认入院条件和就医流程。
- 遇到异常情况时按医院指引处理。

## 每周固定动作

- 检查待产包。
- 更新产检和入院计划。
- 确认证件资料是否齐全。
- 复盘本周妈妈最需要支持的事项。
