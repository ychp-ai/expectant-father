# 孕中期爸爸任务

## 阶段重点

孕中期通常相对稳定，适合把产检节奏、家庭分工、物资规划和基础照护学习建立起来。

## 你需要主动承担

- [ ] 跟进行动计划中的产检预约。
- [ ] 整理中期检查报告和医生建议。
- [ ] 和妈妈一起规划家庭分工。
- [ ] 开始整理待产包、宝宝用品和家庭空间。
- [ ] 学习基础的新生儿照护知识。
- [ ] 关注妈妈睡眠、腰背不适和活动量。
- [ ] 产前筛查或家族史提示需要遗传咨询时共同参加；医生要求检查爸爸时按时完成。

## 陪产检任务

- 提前确认检查时间窗口和预约状态。
- 准备孕期档案、证件和既往报告。
- 产检后记录是否需要复查。
- 把后续项目加入日历提醒。

## 家庭准备

- 梳理家里哪些事情必须由你接手。
- 提前确认谁可以在临产和产后帮忙。
- 规划宝宝床、收纳、洗护、喂养相关空间。
- 建立物资清单，不盲目囤货。

## 沟通建议

- 讨论预算时先分优先级，不直接否定需求。
- 对妈妈身体变化保持尊重和耐心。
- 产检结果不清楚时，一起问医生，不自行判断。

## 每周固定动作

- 跟进行动计划完成度。
- 更新检查报告归档。
- 推进一个家庭准备事项。
- 和妈妈确认是否需要调整生活节奏。
