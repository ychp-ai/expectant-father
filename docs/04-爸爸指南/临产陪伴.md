# 临产陪伴指南

## 阶段重点

临产阶段爸爸的重点是保持冷静、执行流程、协助沟通、照顾妈妈感受，并把信息记录清楚。

## 出发前确认

- [ ] 确认是否符合医院建议的就医条件。
- [ ] 带上证件、医保、孕期档案和全部报告。
- [ ] 带上待产包、手机、充电器和必要现金或支付工具。
- [ ] 通知约定好的家人或联系人。
- [ ] 确认路线、入口和停车方案。

## 到院后任务

- 负责挂号、登记、缴费和资料提交。
- 帮妈妈减少重复沟通，把关键信息告诉医护人员。
- 记录医生说明的下一步流程。
- 根据医院规定确认陪护要求。

## 陪伴方式

- 用短句确认需求：“要喝水吗”“要我扶你吗”“要不要换姿势”。
- 不争论、不催促、不把压力转移给妈妈。
- 遇到流程变化时先听医护说明，再和妈妈沟通。
- 妈妈疼痛或紧张时，优先陪伴和回应，不做过多解释。

- 到院时间：
- 医生建议：
- 当前流程：
- 下一步安排：
- 需要补交的资料：
- 已通知联系人：

## 常见提醒

- 不自行判断是否可以等待。
- 不在关键时刻临时翻找证件和报告。
- 不把家人群消息放在妈妈需求之前。
- 不擅自做医疗决定，关键问题听医生说明。
