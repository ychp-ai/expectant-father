# 孕早期爸爸任务

## 阶段重点

孕早期的重点是确认怀孕、完成首次产检和建档准备，同时帮助妈妈降低不确定感。

## 你需要主动承担

- [ ] 记录末次月经日期、确认怀孕日期和首次就诊日期。
- [ ] 查询目标医院的预约、建档和资料要求。
- [ ] 准备身份证、医保卡、既往报告等材料。
- [ ] 建立孕期文件夹，保存检查报告和缴费记录。
- [ ] 把重要时间同步到家庭日历。
- [ ] 关注妈妈的疲劳、恶心、食欲和情绪变化。

## 陪产检任务

- 提前确认挂号方式、科室、路线和停车。
- 产检当天负责证件、排队、缴费和报告领取。
- 记录医生说明的后续检查时间。
- 回家后整理报告和下一步待办。

## 沟通建议

- 多问“今天哪里不舒服”“有什么需要我做”。
- 少说“别人都这样”“忍一忍”。
- 不把所有决定都推给妈妈。
- 有分歧时先记录问题，再一起咨询医生。

## 每周固定动作

- 更新一次孕期日历。
- 整理一次报告和待办。
- 检查是否有未预约的产检。
- 和妈妈确认下周最需要你支持的事情。
