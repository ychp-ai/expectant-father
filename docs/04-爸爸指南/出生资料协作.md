# 出生资料协作

本页只保留宝宝出生后的基本信息登记和办事协作，不扩展新生儿照护或产后恢复内容。

## 资料登记

- [ ] 记录出生日期、时间、地点等基础信息。
- [ ] 保存医院提供的出生和出院材料。
- [ ] 保存费用票据、缴费记录及需要领取的报告。
- [ ] 确认出生医学证明等资料的领取要求。

## 办事协作

- [ ] 查看[杭州新生儿出生一件事](../06-办事指南/杭州新生儿出生一件事.md)，核对当次联办条件。
- [ ] 逐项确认出生医学证明、户籍登记、预防接种证或接种档案、新生儿基本医保参保及缴费是否办结；联办申请不等于每项都已完成。
- [ ] 符合杭州参保条件时，把“出生后 3 个月内完成参保并缴费”设为明确截止提醒，以免影响按现行规则从出生之日起享受当年度待遇。
- [ ] 分开跟踪生育津贴、杭州现行孕产补助、育儿补助、三孩补助和 3 岁以下婴幼儿照护个税专项附加扣除；这些事项不随“出生一件事”自动办结。
- [ ] 在双方单位分别设置育儿假周年提醒；协助妈妈在复工前确认哺乳时间和排班保护。
- [ ] 符合多子女家庭条件且有购房或租房提取需求时，另行核对杭州公积金优惠。
- [ ] 确认办理时间、渠道、材料和是否需要父母双方到场。
- [ ] 复印或扫描重要资料，原件集中保管。
- [ ] 把办理状态、回执编号和下一步加入家庭清单，并把实际信息记录到私人位置。

## 爸爸负责

- 维护资料目录和办理日历。
- 核对材料，不在公开仓库保存证件号码或报告照片。
- 记录官方咨询渠道和工作人员说明，不依赖过期攻略。
- 与妈妈确认姓名等家庭决定后再提交资料。
