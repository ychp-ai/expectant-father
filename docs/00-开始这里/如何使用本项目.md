# 如何使用本项目

## 开始前准备

- 确认当前孕周和预产期以医生或检查记录为准。
- 记录主要产检医院、联系电话、到院路线和紧急联系人。
- 准备家庭日历以及安全的报告归档位置。
- 只复制需要的模板，不在公开仓库保存个人医疗和证件信息。

## 方式一：按孕周使用

1. 找到当前孕周。
2. 阅读本周母体与胎儿状态。
3. 查看对应的阶段行动计划和产检入口。
4. 选择本周真正需要执行的事项，不必照搬所有建议。
5. 把本周记录字段复制到个人资料仓库的当前记录页或其他私人记录工具，再更新本周状态和下周待办。

## 方式二：按专题使用

当你需要了解某件具体事情时，进入对应模块：

- 检查：查看[产检指南](../03-产检指南/README.md)。
- 待办：查看[行动计划](../02-行动计划/README.md)。
- 爸爸任务：查看[爸爸指南](../04-爸爸指南/README.md)。
- 物品准备：查看[物资准备](../05-物资准备/README.md)。
- 证件手续：查看[办事指南](../06-办事指南/README.md)。
- 风险信号：查看当前孕周文档中的风险提醒；如有不适或异常，请及时联系产科医生或前往医院。

## 方式三：围绕一次产检使用

### 产检前

- 查看医院通知，确认时间、地点、是否需要预约或空腹。
- 整理证件、既往报告和准备咨询医生的问题。
- 安排交通、陪同和可能需要的请假时间。

### 产检后

- 保存原始报告，不只记录自己的理解。
- 写下医生说明、下次时间和需要复查的事项。
- 把后续任务同步到家庭日历和执行清单。

## 建议维护节奏

- 每周固定一天更新私人位置中的本周记录。
- 每次产检后整理报告和医生建议。
- 每月回顾一次后续 4～8 周的检查和准备事项。

## 记录与隐私

- 仓库中的模板是空白示例，建议复制到私人记录工具后使用。
- 孕周文档的“本周记录”只提供字段，不在通用文档原位填写；个人状态统一写入个人资料仓库的当前记录页或其他受控私人记录工具。
- 公开分享前删除姓名、证件号、住址、电话、医院编号和报告二维码。
- 医生口头建议尽量记录日期和场景；检查结果以原始报告为准。
