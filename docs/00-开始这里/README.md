# 开始这里

这里是第一次使用本项目的入口。你不需要按顺序读完整个仓库，先根据当前问题选择一条路径即可。

默认地区为浙江杭州，主要医院为浙江大学医学院附属妇产科医院；使用前先阅读[使用范围](./使用范围.md)。

## 第一次使用建议

1. 向产科医生或根据检查记录确认当前孕周。
2. 打开对应孕周文档，记录本周待办。
3. 查看未来一个阶段的行动计划，把需要预约的事项加入日历。
4. 建立一个仅家庭成员可访问的文件夹，保存报告照片、医生建议和办事资料。

> 提醒：本项目帮助整理信息和行动，不用于自行诊断、选择药物或替代就医。
