# 整个孕期时间线

本页只提供整体视角。具体检查项目和时间可能因个人情况、医院流程及当地政策不同。

需要同时核对孕妇、爸爸和家庭任务时，使用[整个孕期三方检查与行动表](./整个孕期三方检查与行动表.md)。

杭州社区、政务、医保、单位和分娩前办理事项统一从[杭州孕期必办事项](../07-执行清单/杭州孕期必办事项.md)进入。

## 孕早期：第 1～12 周

重点：在医生指导下确认妊娠和孕周，完成首次妊娠风险筛查、基础检查、建档准备及限时产前筛查知情选择。

家庭任务：确定主要就诊医院，联系常住地社区建小卡，办理生育登记，核对杭州职工医保状态；女方了解产检和孕期劳动保护，男方确认单位权益入口，并建立报告归档方式。

入口：[孕早期孕周文档](../01-孕期管理/孕早期/第01周.md) / [孕 5～7 周行动计划](../02-行动计划/孕5-7周.md)

## 孕中期：第 13～27 周

重点：持续常规复诊和血尿等医生安排的复查；完成产前筛查知情选择、中期超声、胎动关注和糖代谢检查。

家庭任务：提前确认检查是否需要预约，保存筛查和超声报告，持续处理社区随访、产检时间和单位手续。

入口：[孕中期孕周文档](../01-孕期管理/孕中期/第13周.md) / [孕中期相关行动计划](../02-行动计划/README.md)

## 孕晚期：第 28～40 周

重点：持续风险评估，复查肝肾功能等医生安排项目，评估胎儿生长与胎位，确认 B 族链球菌等孕晚期筛查、胎心监护和分娩前检查安排。

家庭任务：按医院安排产检，确认浙大妇院实际分娩院区和急诊路径；复核医保连续缴费，确认女方产假、男方护理假、双方育儿假、津贴衔接及入院材料。

入口：[孕晚期孕周文档](../01-孕期管理/孕晚期/第28周.md) / [待产准备清单](../07-执行清单/待产准备清单.md)

## 出生后

重点：登记出生基本信息，整理医院文件，并按当地要求跟进出生医学证明、户籍、预防接种、新生儿医保参保缴费等必要事项。

家庭任务：保存出生资料和票据，逐项确认联办结果；另行核对生育津贴、夫妻育儿假、女方哺乳期劳动保护、杭州现行补助和个税事项。

入口：[出生资料协作](../04-爸爸指南/出生资料协作.md) / [出生资料清单](../07-执行清单/出生资料清单.md)

> 提醒：具体检查时间请以产科医生和医院安排为准。
