# 使用范围

## 默认使用场景

- 使用方式：仓库维护者及家庭自用。
- 核心阶段：孕 1～40 周的行动、产检、记录和待产准备。
- 默认地区：浙江省杭州市。
- 默认医院：浙江大学医学院附属妇产科医院。
- 出生后范围：仅保留出生基本信息、文件归档和必要办事登记。

## 地区与医院边界

项目中的建档、预约、检查、缴费、入院和材料准备，默认优先考虑杭州及浙江大学医学院附属妇产科医院的实际使用场景，但不把可能变化的流程写成永久规则。

- 每次预约都应重新确认院区、科室、时间和报到地点。
- 建档条件、检查项目、材料清单和入院要求以医院最新通知及医护人员说明为准。
- 医保、户籍和其他政务事项以杭州市及实际办理地的官方要求为准。
- 转院、外院检查或医生另有安排时，以当次医疗安排为准，不强行套用默认医院流程。

## 内容限制

- 不根据仓库内容自行判断检查结果、调整药物或决定治疗方案。
- 不把通用孕周描述当作个人诊断。
- 不扩展品牌推荐、长期育儿或新生儿照护专题。
- 不在仓库中保存姓名、证件号码、电话、住址、病历号、报告照片或二维码。

## 需要单独记录但不提交的内容

以下信息应放在私人记录工具中：

- 当前孕周和预产期。
- 实际就诊院区、科室和医生。
- 医院联系电话及到院路线。
- 预约记录、检查报告和医生建议。
- 家庭联系人、证件信息和办理回执。

个人化进度应保存在用户指定的独立、访问受控的私人资料仓库或其他私人记录工具中。使用 Git 时应采用独立历史并按该仓库自身的隐私、提交和推送约定维护；本通用知识库不固定其仓库名称或本地位置。

> 提醒：本页只定义项目默认范围，不代表浙江大学医学院附属妇产科医院的官方流程说明。
