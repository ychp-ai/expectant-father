# 项目介绍

Expectant Father 是一份面向准爸爸和家庭的孕期行动手册。

当前版本主要供维护者家庭自用，默认地区为浙江杭州，主要医院为浙江大学医学院附属妇产科医院。详见[使用范围](./使用范围.md)。

它不只是解释孕期知识，而是帮助家庭在整个孕期知道：

- 当前阶段可能发生什么
- 本周应该完成什么
- 哪些检查需要提前预约
- 需要准备哪些物品和证件
- 哪些情况需要及时联系医生
- 每次产检后应该记录什么

## 项目包含什么

- **孕周信息**：按第 1～40 周查看当前阶段和记录模板。
- **行动计划**：按时间窗口安排预约、资料和家庭任务。
- **专题指南**：集中处理产检、爸爸任务、物资和办事事项。
- **执行工具**：使用清单和模板持续记录，而不是只读一次。

## 项目不做什么

- 不判断检查结果是否正常。
- 不推荐具体药物、剂量或治疗方案。
- 不代替医院的预约规则、材料清单和当地政策。
- 不假定浙江大学医学院附属妇产科医院的院区、科室或流程长期不变。
- 不要求把真实姓名、证件号码、检查报告等隐私提交到仓库。

## 内容原则

- 行动建议尽量写清“什么时候、准备什么、谁负责、如何记录”。
- 医学和流程信息链接到[参考资料](../../references/README.md)，并注明复核日期。
- 不同资料存在差异时，以产科医生、就诊医院和当地官方要求为准。

> 说明：本项目内容仅用于孕期管理参考，不能替代医生诊疗意见。如有不适或异常，请及时联系产科医生或前往医院。
