# 知识速查目录

不知道知识放在哪时，从本页找，不需要先理解文件夹结构。

- **有一件事要办**：看[常见场景入口](#常见场景入口)，按“了解 → 准备 → 记录”找到所需资料。
- **知道孕周**：看[孕周直达表](#孕周直达表)，直接打开本周知识或阶段行动。
- **记得一个词**：用 **⌘F / Ctrl+F** 搜索，例如“羊穿”“OGTT”“GBS”“妊娠油”“陪产假”；下方表格收录常用叫法，链接可直达文章或章节。
- **想浏览全部分类**：看[按问题查找](#按问题查找)和[各目录放什么](#各目录放什么)。

本页只负责定位知识，具体说明、适用条件、来源和最近复核日期见链接正文。
