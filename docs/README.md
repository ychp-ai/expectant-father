# 知识速查目录

不知道某个知识放在哪时，从本页找。按问题点击下方分类，或用 **⌘F / Ctrl+F** 搜索关键词，例如“无创”“糖耐”“报销”“请假”“流感”。表格中的链接直接进入具体文章；只想浏览文件分类时，看[各目录放什么](#各目录放什么)。

本页只负责定位知识，具体说明、适用条件、来源和最近复核日期见链接正文。

| 目录 | 什么时候去这里找 |
|---|---|
| [00-开始这里](./00-开始这里/README.md) | 第一次使用、全孕期总览、时间线、FAQ 和使用边界 |

| [06-办事指南](./06-办事指南/README.md) | 想了解社区、医院行政、政务、医保或单位事项怎样办 |
| [07-执行清单](./07-执行清单/README.md) | 已了解说明，想逐项勾选和检查遗漏 |
