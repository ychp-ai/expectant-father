# 到院用品

## 目标

整理到医院时需要随身携带和随时查看的物品。

## 资料

- [ ] 证件。
- [ ] 卡片。
- [ ] 孕期档案。
- [ ] 检查报告。
- [ ] 预约记录。

## 随身物品

- [ ] 手机。
- [ ] 充电器。
- [ ] 移动电源。
- [ ] 水杯。
- [ ] 纸巾。
- [ ] 简单食品。

## 信息

- [ ] 医院地址。
- [ ] 入口位置。
- [ ] 停车位置。
- [ ] 联系人电话。

## 爸爸负责

- 出发前检查。
- 到院后登记和提交资料。
- 保管报告和票据。
- 记录流程。
