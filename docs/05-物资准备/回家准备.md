# 回家准备

## 准备目标

提前整理出院回家后第一周需要用到的空间、物品和家庭分工。

## 家庭空间

- [ ] 睡眠区域整理好。
- [ ] 喂养区域方便取物。
- [ ] 清洁用品放在固定位置。
- [ ] 夜间照明可用。
- [ ] 垃圾袋和收纳用品充足。

## 消耗品

- [ ] 纸巾。
- [ ] 湿巾或棉柔巾。
- [ ] 清洁用品。
- [ ] 常用换洗物品。
- [ ] 家庭食品和饮用水。

## 家庭分工

- [ ] 谁负责做饭或订餐。
- [ ] 谁负责清洁。
- [ ] 谁负责采购。
- [ ] 谁负责夜间协助。
- [ ] 谁负责亲友沟通。

## 出院当天

- [ ] 确认路线和车辆。
- [ ] 检查证件和出院资料。
- [ ] 带齐所有物品。
- [ ] 回家后先让妈妈和宝宝休息。

## 爸爸负责

- 提前完成家庭环境整理。
- 出院前检查物品。
- 回家后控制探视频率。
- 每天复盘需要补充的物品。
