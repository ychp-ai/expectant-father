# 妈妈用品

## 准备目标

整理妈妈在孕期、住院和回家后可能需要的基础用品。

## 日常用品

- [ ] 宽松衣物。
- [ ] 舒适鞋袜。
- [ ] 水杯。
- [ ] 纸巾和湿巾。
- [ ] 文件袋。
- [ ] 充电器和移动电源。

## 住院用品

- [ ] 换洗衣物。
- [ ] 洗漱用品。
- [ ] 拖鞋。
- [ ] 毛巾。
- [ ] 出院衣物。

## 回家用品

- [ ] 家居服。
- [ ] 小物收纳盒。
- [ ] 靠垫或枕头。
- [ ] 常用清洁用品。

## 爸爸负责

- 记录尺码和偏好。
- 负责采购、收货和整理。
- 按待产包、医院、回家三类分类。
- 定期检查是否遗漏。
