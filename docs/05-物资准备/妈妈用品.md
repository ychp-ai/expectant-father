# 妈妈用品

## 准备目标

整理妈妈在孕期和住院期间可能需要的基础用品。

## 日常用品

- [ ] 宽松衣物。
- [ ] 舒适鞋袜。
- [ ] 水杯。
- [ ] 纸巾和湿巾。
- [ ] 文件袋。
- [ ] 充电器和移动电源。

### 可选皮肤护理用品

- [ ] 成分简单、本人耐受的无香保湿霜、润肤剂或身体护理油，按皮肤干燥和舒适需求选择，不属于孕期必买品。
- [ ] 首次只准备小包装或单品试用，不因“预防妊娠纹”宣传囤货。
- [ ] 购买前按照专题页核对产品标签、全成分表和试用方法。

妊娠油主要用于保湿，没有可靠证据保证预防或消除妊娠纹。具体选择和使用方法见[孕期皮肤护理与妊娠油](../01-孕期管理/孕期皮肤护理与妊娠油.md)。

## 住院用品

- [ ] 换洗衣物。
- [ ] 洗漱用品。
- [ ] 拖鞋。
- [ ] 毛巾。
- [ ] 出院衣物。

## 回家用品

- [ ] 家居服。
- [ ] 小物收纳盒。
- [ ] 靠垫或枕头。
- [ ] 常用清洁用品。

## 爸爸负责

- 记录尺码和偏好。
- 负责采购、收货和整理。
- 按待产包、医院、回家三类分类。
- 定期检查是否遗漏。
