# 待产包

## 准备目标

把入院时需要随身携带的核心物品集中打包，避免临时翻找。

## 证件资料

- [ ] 身份证。
- [ ] 医保卡。
- [ ] 孕期档案。
- [ ] 检查报告。
- [ ] 住院或入院相关材料。

## 妈妈用品

- [ ] 换洗衣物。
- [ ] 洗漱用品。
- [ ] 拖鞋。
- [ ] 毛巾。
- [ ] 水杯。

## 宝宝用品

- [ ] 衣物。
- [ ] 包被。
- [ ] 清洁用品。
- [ ] 出院用品。

## 陪护用品

- [ ] 手机和充电器。
- [ ] 移动电源。
- [ ] 简单食品和水。
- [ ] 备用衣物。
- [ ] 纸巾和湿巾。

## 打包方式

- 证件资料单独收纳。
- 妈妈用品和宝宝用品分袋。
- 常用物品放在最容易拿的位置。
- 包外贴上清单。

## 爸爸负责

- 每周检查一次。
- 确认物品位置。
- 出发前负责携带。
- 用完后及时补充。
