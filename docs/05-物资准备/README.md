# 物资准备

本模块整理孕期、入院待产和宝宝出生后首月的基础日常用品，不扩展长期育儿用品规划。

目标不是一次买齐所有东西，而是按阶段、按场景、按优先级逐步准备，避免遗漏和重复购买。

## 使用方式

- 先看总览，再按场景进入具体清单。
- 将清单复制到私人位置，记录现有量、缺口和状态：未准备、已下单、已到货、已清洗、已打包。
- 临近孕晚期时重点检查待产包、到院用品和医院要求的出院物品。
- 两份主清单均标注最低准备量和推荐准备量；先补最低缺口，再根据洗晒、补送和喂养方式增减。数量属于家庭预算，不是医学标准或医院规定。
- 推荐量是总量；住院带回的衣物、耐用品可继续使用，不重复采购。

## 准备原则

- 先刚需，后可选。
- 先确认医院要求，再准备入院物品。
- 先小批量试用，再大量囤货。
- 物品到家后及时清洗、分类和打包。
- 清单由爸爸负责维护，妈妈负责确认偏好。
