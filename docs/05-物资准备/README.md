# 物资准备

本模块用于整理孕期和入院待产所需物资，不扩展出生后的长期用品规划。

目标不是一次买齐所有东西，而是按阶段、按场景、按优先级逐步准备，避免遗漏和重复购买。

## 使用方式

- 先看总览，再按场景进入具体清单。
- 每项物资建议标记状态：未准备、已下单、已到货、已清洗、已打包。
- 临近孕晚期时重点检查待产包、到院用品和医院要求的出院物品。
- 具体品牌、型号和数量根据家庭预算、医院要求和实际生活方式决定。

## 准备原则

- 先刚需，后可选。
- 先确认医院要求，再准备入院物品。
- 先小批量试用，再大量囤货。
- 物品到家后及时清洗、分类和打包。
- 清单由爸爸负责维护，妈妈负责确认偏好。
