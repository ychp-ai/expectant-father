# 行动计划

本模块按孕周阶段整理“什么时候做什么”。

与单纯的知识说明不同，行动计划重点回答：

- 这个阶段的重点是什么
- 需要预约什么
- 需要准备什么资料
- 爸爸需要做什么
- 完成后需要记录什么
- 下一个阶段要提前关注什么

> 提醒：具体检查安排、建档流程和资料要求请以产科医生、医院和当地政策为准。
