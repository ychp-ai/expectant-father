# 孕 21～24 周行动计划

## 本阶段重点

这个阶段的核心是完成大排畸或系统超声，并根据检查结果安排后续复查或常规产检。

同时，需要开始为 24～28 周的糖耐量检查做准备，提前了解是否需要预约、是否需要空腹以及当天耗时。

## 需要完成

- [ ] 按预约完成大排畸或系统超声。
- [ ] 保存检查报告和影像资料。
- [ ] 记录医生对检查结果的说明和后续建议。
- [ ] 了解糖耐量检查的时间、流程和注意事项。
- [ ] 继续记录体重、血压和胎动情况。
- [ ] 初步规划宝宝用品和待产相关预算。

## 提前预约

- [ ] 糖耐量检查或下一次产检。
- [ ] 如医生建议复查，及时预约复查时间。

## 提前准备

- 大排畸预约信息
- 产检手册或建档资料
- 已有检查报告
- 糖耐量检查注意事项
- 检查当天交通安排

## 爸爸任务

- [ ] 陪同大排畸检查或协助安排交通。
- [ ] 记录医生说明和后续安排。
- [ ] 保存纸质报告和电子照片。
- [ ] 查询糖耐量检查流程，提醒是否需要空腹。
- [ ] 开始建立宝宝用品预算，不急于一次性采购。
