# 孕 17～20 周行动计划

## 本阶段重点

这个阶段进入孕中期中段，重点是继续稳定产检节奏，并提前关注 20～24 周的大排畸安排。

如果医院预约紧张，大排畸通常需要提前预约，不建议等到临近检查窗口才处理。

## 需要完成

- [ ] 确认下一次产检时间。
- [ ] 了解大排畸检查的预约方式和建议时间。
- [ ] 持续记录每周体重和血压。
- [ ] 整理此前产检报告。
- [ ] 关注胎动出现情况，但不要因个体差异过度焦虑。
- [ ] 规划后续 4～6 周的产检和工作安排。

## 提前预约

- [ ] 大排畸或系统超声。
- [ ] 后续常规产检。

## 提前准备

- 已有产检报告
- 产检手册或建档资料
- 目标医院预约渠道
- 想咨询医生的问题
- 体重和血压记录

## 爸爸任务

- [ ] 帮忙确认大排畸预约时间。
- [ ] 协调陪同检查的请假或交通安排。
- [ ] 整理报告文件夹，按日期保存资料。
- [ ] 每周提醒更新体重、血压和待办。
- [ ] 开始了解孕中期和孕晚期主要检查节点。

## 完成后记录

- 大排畸是否已预约：是 / 否
- 预约时间：
- 下次产检时间：
- 本阶段体重变化：
- 本阶段血压记录：
- 需要咨询医生的问题：

## 风险提醒

> 提醒：如出现明显不适、异常出血、持续疼痛或其他让你担心的情况，请及时联系医生或前往医院。
