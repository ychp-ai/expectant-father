# 孕 17～20 周行动计划

## 本阶段重点

这个阶段进入孕中期中段，重点是继续稳定产检节奏，确认此前筛查结果已由医生解读，并提前关注 20～24+6 周中期超声筛查安排。

如果医院预约紧张，中期超声筛查通常需要提前预约，不建议等到临近检查窗口才处理。

## 需要完成

- [ ] 确认下一次产检时间。
- [ ] 按医生安排完成本阶段常规复诊及血尿等复查。
- [ ] 了解中期超声筛查的预约方式，确认检查日期处于 20～24+6 周。
- [ ] 确认此前产前筛查报告已由医生解读，需要进一步咨询或检查时按时衔接。
- [ ] 持续记录每周体重和血压。
- [ ] 整理此前产检报告。
- [ ] 关注胎动出现情况，但不要因个体差异过度焦虑。
- [ ] 规划后续 4～6 周的产检和工作安排。

## 提前预约

- [ ] 中期超声筛查或医院所称的系统超声。
- [ ] 后续常规产检。

## 提前准备

- 已有产检报告
- 产检手册或建档资料
- 目标医院预约渠道
- 想咨询医生的问题
- 体重和血压记录

## 爸爸任务

- [ ] 帮忙确认大排畸预约时间。
- [ ] 协调陪同检查的请假或交通安排。
- [ ] 整理报告文件夹，按日期保存资料。
- [ ] 每周提醒更新体重、血压和待办。
- [ ] 开始了解孕中期和孕晚期主要检查节点。

## 完成后记录

把中期超声预约、复诊、体重、血压和医生问题记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：如出现明显不适、异常出血、持续疼痛或其他让你担心的情况，请及时联系医生或前往医院。
