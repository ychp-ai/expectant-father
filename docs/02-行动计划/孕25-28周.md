# 孕 25～28 周行动计划

## 本阶段重点

这个阶段的核心是完成糖耐量检查，并继续稳定记录体重、血压和胎动情况。

糖耐量检查通常对时间、饮食和空腹状态有要求，建议提前了解医院说明，预留足够时间。

## 需要完成

- [ ] 确认糖耐量检查时间和医院要求。
- [ ] 按医院要求完成糖耐量检查。
- [ ] 保存检查报告。
- [ ] 记录医生对结果的说明和后续建议。
- [ ] 持续记录体重、血压和胎动。
- [ ] 开始梳理待产包和宝宝用品清单。

## 提前预约

- [ ] 糖耐量检查或本阶段产检。
- [ ] 孕晚期常规产检。

## 提前准备

- 糖耐量检查预约信息
- 医院关于饮食和空腹的说明
- 产检手册或建档资料
- 已有检查报告
- 水杯、充电器和可等待的时间安排

## 爸爸任务

- [ ] 提醒检查当天时间和注意事项。
- [ ] 如方便，陪同检查并安排交通。
- [ ] 帮忙保存报告并记录医生建议。
- [ ] 开始整理待产包初版清单。
- [ ] 和孕妇一起讨论宝宝用品预算和购买优先级。

## 风险提醒

> 提醒：糖耐量检查结果和后续饮食管理应以医生建议为准，不建议自行判断或自行调整方案。
