# 孕 25～28 周行动计划

## 本阶段重点

这个阶段的核心是完成糖耐量检查，并继续稳定记录体重、血压和胎动情况。

糖耐量检查通常对时间、饮食和空腹状态有要求，建议提前了解医院说明，预留足够时间。

## 需要完成

- [ ] 确认糖耐量检查时间和医院要求。
- [ ] 按医院要求完成糖耐量检查。
- [ ] 保存检查报告。
- [ ] 记录医生对结果的说明和后续建议。
- [ ] 持续记录体重、血压和胎动。
- [ ] 按医生安排完成宫高、胎心及血尿等常规复诊项目。
- [ ] 开始梳理待产包和宝宝用品清单。
- [ ] 开始确认女方产检与岗位保护、一孩 158 天或二孩三孩 188 天产假、工资与生育津贴衔接流程。
- [ ] 男方确认 15 天护理假，夫妻双方确认子女三周岁内每周年各 10 天育儿假入口。
- [ ] 建立分娩前行政资料包初版。
- [ ] 核对是否符合杭州二孩、三孩孕产补助条件；符合时在孕满 24 周后按现行入口申请。

## 提前预约

- [ ] 糖耐量检查或本阶段产检。
- [ ] 孕晚期常规产检。

## 提前准备

- 糖耐量检查预约信息
- 医院关于饮食和空腹的说明
- 产检手册或建档资料
- 已有检查报告
- 水杯、充电器和可等待的时间安排

## 爸爸任务

- [ ] 提醒检查当天时间和注意事项。
- [ ] 如方便，陪同检查并安排交通。
- [ ] 帮忙保存报告并记录医生建议。
- [ ] 开始整理待产包初版清单。
- [ ] 和孕妇一起讨论宝宝用品预算和购买优先级。

## 完成后记录

把糖代谢检查、常规复诊、医生建议、下次产检、待产包、单位手续及符合条件时的孕产补助办理状态记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：糖耐量检查结果和后续饮食管理应以医生建议为准，不建议自行判断或自行调整方案。
