# 孕 33～36 周行动计划

## 本阶段重点

这个阶段进入孕晚期后半段，重点是按医生安排完成后续产检、胎心监护和必要筛查，并把待产准备从“计划”推进到“基本完成”。

此阶段建议把入院资料、待产包、医院路线、陪产安排和紧急联系人都整理好。

## 需要完成

- [ ] 确认本阶段产检时间和频率。
- [ ] 按医生安排进行胎心监护或其他检查。
- [ ] 了解是否需要 B 族链球菌筛查，以及医院安排时间。
- [ ] 完善待产包，并按妈妈、宝宝、爸爸、证件资料分类。
- [ ] 确认生产医院路线、停车位置和夜间入口。
- [ ] 准备入院所需证件和产检资料。
- [ ] 明确临产时谁负责联系医院、开车、拿待产包和通知家人。

## 提前预约

- [ ] 孕晚期常规产检。
- [ ] 胎心监护。
- [ ] B 族链球菌筛查（如医院或医生安排）。

## 提前准备

- 身份证
- 医保卡
- 产检手册或建档资料
- 所有重要检查报告
- 待产包
- 医院路线和停车方案
- 紧急联系人清单

## 爸爸任务

- [ ] 检查待产包是否基本齐全。
- [ ] 熟悉去医院路线，最好实际走一遍。
- [ ] 保存医院电话、产科电话和紧急联系人。
- [ ] 确认夜间出发方案。
- [ ] 记录医生关于入院时机的说明。
- [ ] 准备自己的陪护用品，如充电器、水杯、外套和换洗衣物。

## 风险提醒

> 提醒：孕晚期如出现明显不适、胎动明显变化、规律宫缩、破水、出血或其他让你担心的情况，请及时联系医生或前往医院。

## 下一阶段预告

孕 37～40 周进入足月阶段，重点是持续产检、识别临产信号、保持手机畅通，并随时准备出发去医院。
