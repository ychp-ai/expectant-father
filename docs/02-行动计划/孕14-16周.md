# 孕 14～16 周行动计划

## 本阶段重点

这个阶段通常进入孕中期，整体状态可能比孕早期更稳定。

核心任务是建立长期记录习惯，并根据医生说明完成产前筛查的知情选择。血清学筛查、孕妇外周血胎儿游离 DNA 筛查和产前诊断不是同一个项目，也没有适用于所有人的统一时间表。

## 需要完成

- [ ] 确认下一次产检时间。
- [ ] 按医生安排完成体重、血压、宫高、胎心及血尿等常规复诊项目。
- [ ] 向医生确认当前适用的筛查路径、时间、检测范围、局限和异常后的下一步。
- [ ] 如已建小卡，核对免费中期血清学产前筛查券或登记状态、有效孕周和社区预约；免费服务按已确认口径只能在所属社区卫生院（社区卫生服务中心）办理。
- [ ] 建立每周体重和血压记录。
- [ ] 继续保存所有检查报告。
- [ ] 规划后续 4～8 周的检查时间。
- [ ] 开始关注孕中期饮食、运动和睡眠节奏。
- [ ] 腹部、大腿等部位出现干燥或紧绷时，可按耐受情况选择保湿霜或妊娠油；先试用一种，不为防纹增加用量或叠加产品。
- [ ] 如口腔医生建议在孕中期处理已有龋病、牙周问题或其他口腔疾病，确认治疗、影像、麻醉和用药方案已结合孕周及产科情况评估；没有问题时继续日常口腔清洁即可。

## 提前准备

- 已有检查报告
- 下次产检预约信息
- 筛查项目问题清单
- 体重记录方式
- 血压记录方式

## 爸爸任务

- [ ] 和孕妇一起确认筛查项目的医生建议。
- [ ] 协助规划后续产检时间，避免和工作安排冲突。
- [ ] 建立家庭孕期文件夹，按日期保存报告。
- [ ] 每周提醒更新体重、血压和待办。
- [ ] 逐步了解孕中期重点事项，不急于大量采购。

## 完成后记录

把复诊结果、筛查选择、体重、血压、医生问题和下次产检记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：筛查项目的选择应结合年龄、既往情况、医生建议和家庭意愿，不建议仅根据网络信息自行决定。
