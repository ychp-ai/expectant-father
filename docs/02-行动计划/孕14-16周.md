# 孕 14～16 周行动计划

## 本阶段重点

这个阶段通常进入孕中期，整体状态可能比孕早期更稳定。

核心任务是建立长期记录习惯，并根据医生建议规划唐筛或无创 DNA 等筛查项目。

## 需要完成

- [ ] 确认下一次产检时间。
- [ ] 根据医生建议了解唐筛或无创 DNA 的时间和选择。
- [ ] 建立每周体重和血压记录。
- [ ] 继续保存所有检查报告。
- [ ] 规划后续 4～8 周的检查时间。
- [ ] 开始关注孕中期饮食、运动和睡眠节奏。

## 提前准备

- 已有检查报告
- 下次产检预约信息
- 筛查项目问题清单
- 体重记录方式
- 血压记录方式

## 爸爸任务

- [ ] 和孕妇一起确认筛查项目的医生建议。
- [ ] 协助规划后续产检时间，避免和工作安排冲突。
- [ ] 建立家庭孕期文件夹，按日期保存报告。
- [ ] 每周提醒更新体重、血压和待办。
- [ ] 逐步了解孕中期重点事项，不急于大量采购。

## 风险提醒

> 提醒：筛查项目的选择应结合年龄、既往情况、医生建议和家庭意愿，不建议仅根据网络信息自行决定。
