# 孕 37～40 周行动计划

## 本阶段重点

这个阶段通常已经进入足月范围，重点是继续按医生安排产检，识别临产信号，并确保入院准备、家庭分工和出生资料登记方式已经明确。

此阶段不建议再新增大量复杂计划，而是保持稳定、减少奔波、随时准备出发。

## 需要完成

- [ ] 按医生安排完成每周或更频繁的产检。
- [ ] 确认血常规、尿常规、凝血及医院要求的分娩前项目已经完成或有入院后安排。
- [ ] 持续记录胎动、体重、血压和身体变化。
- [ ] 确认待产包已经放在固定位置。
- [ ] 确认所有入院证件和检查资料已经归档。
- [ ] 最终确认医保状态、院端生育信息登记方式和本人津贴收款账户。
- [ ] 最终确认女方产假、男方护理假和双方育儿假的单位申请入口及必要证明。
- [ ] 确认医院路线、停车位置和夜间入口。
- [ ] 确认宝宝回家用品已经准备好。
- [ ] 把出生医学证明、预防接种证、户籍、新生儿医保参保缴费、生育津贴、补贴和个税事项加入出生后清单。
- [ ] 明确发动时的家庭分工和联系顺序。
- [ ] 保持手机畅通，避免单独长时间外出。

## 提前预约

- [ ] 足月后常规产检。
- [ ] 医生建议的胎心监护或其他检查。
- [ ] 如超过预产期，按医生安排复查或评估。

## 提前准备

- 身份证
- 医保卡
- 产检手册或建档资料
- 重要检查报告
- 待产包
- 手机和充电器
- 医院联系电话
- 家庭分工清单
- 宝宝回家衣物和用品

## 爸爸任务

- [ ] 每天确认手机电量和消息畅通。
- [ ] 确认车况、油量、电量或打车方案。
- [ ] 确认待产包、证件和报告放置位置。
- [ ] 熟悉临产信号和医生给出的入院建议。
- [ ] 负责联系医院、家人和必要支持人员。
- [ ] 保持冷静，协助记录宫缩、破水时间或其他关键情况。
- [ ] 准备宝宝出生后的证件办理和新生儿医保事项清单。

## 完成后记录

把每周产检、分娩前检查、医生建议、待产包、入院资料、医院路线、家庭分工、医保衔接和出生后各项手续提醒记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：如出现规律宫缩、破水、出血、胎动明显变化或其他让你担心的情况，请及时联系医生或前往医院。具体何时入院请以医生建议为准。
