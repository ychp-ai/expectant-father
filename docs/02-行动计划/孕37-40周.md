# 孕 37～40 周行动计划

## 本阶段重点

这个阶段通常已经进入足月范围，重点是继续按医生安排产检，识别临产信号，并确保入院准备、家庭分工和宝宝回家准备都已经就绪。

此阶段不建议再新增大量复杂计划，而是保持稳定、减少奔波、随时准备出发。

## 需要完成

- [ ] 按医生安排完成每周或更频繁的产检。
- [ ] 持续记录胎动、体重、血压和身体变化。
- [ ] 确认待产包已经放在固定位置。
- [ ] 确认所有入院证件和检查资料已经归档。
- [ ] 确认医院路线、停车位置和夜间入口。
- [ ] 确认宝宝回家用品已经准备好。
- [ ] 明确发动时的家庭分工和联系顺序。
- [ ] 保持手机畅通，避免单独长时间外出。

## 提前预约

- [ ] 足月后常规产检。
- [ ] 医生建议的胎心监护或其他检查。
- [ ] 如超过预产期，按医生安排复查或评估。

## 提前准备

- 身份证
- 医保卡
- 产检手册或建档资料
- 重要检查报告
- 待产包
- 手机和充电器
- 医院联系电话
- 家庭分工清单
- 宝宝回家衣物和用品

## 爸爸任务

- [ ] 每天确认手机电量和消息畅通。
- [ ] 确认车况、油量、电量或打车方案。
- [ ] 确认待产包、证件和报告放置位置。
- [ ] 熟悉临产信号和医生给出的入院建议。
- [ ] 负责联系医院、家人和必要支持人员。
- [ ] 保持冷静，协助记录宫缩、破水时间或其他关键情况。
- [ ] 准备宝宝出生后的证件办理和新生儿医保事项清单。

## 风险提醒

> 提醒：如出现规律宫缩、破水、出血、胎动明显变化或其他让你担心的情况，请及时联系医生或前往医院。具体何时入院请以医生建议为准。
