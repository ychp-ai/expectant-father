# 孕 11～13 周行动计划

## 本阶段重点

这个阶段的核心是推进 NT 检查、建档和早孕期阶段复盘。

NT 检查通常有明确的孕周窗口，建议提前确认预约时间和医院要求。

## 需要完成

- [ ] 确认 NT 检查预约时间。
- [ ] 准备建档或继续推进建档流程。
- [ ] 整理孕早期已有检查报告。
- [ ] 记录体重、血压和主要不适变化。
- [ ] 准备下一次产检想确认的问题。
- [ ] 了解孕中期可能涉及的唐筛或无创 DNA。

## 提前准备

- 身份证
- 医保卡
- 已有检查报告
- 建档所需材料
- NT 检查预约信息
- 问题清单

## 爸爸任务

- [ ] 提醒并确认 NT 检查时间。
- [ ] 陪同检查或协助安排交通。
- [ ] 保存检查报告和预约凭证。
- [ ] 记录医生建议和后续安排。
- [ ] 协助整理建档材料。

## 风险提醒

> 提醒：如检查时间、孕周计算或建档流程不确定，请提前联系医院确认，避免错过预约窗口。
