# 孕 11～13 周行动计划

## 本阶段重点

这个阶段的核心是在 11～13+6 周窗口内推进 NT 超声筛查，并在孕 13 周前分别完成社区建小卡和医院围产保健或系统产检记录。

NT 检查通常有明确的孕周窗口，建议提前确认预约时间和医院要求。

## 需要完成

- [ ] 确认 NT 检查预约时间。
- [ ] 确认浙大妇院围产保健或系统产检记录已经建立；如医院仍使用“大卡”等口语，问清正式记录名称、完成标志和后续预约入口。
- [ ] 在孕 13 周前完成社区建小卡和首次孕期健康管理。
- [ ] 确认生育登记已经办结并保存电子服务单。
- [ ] 整理孕早期已有检查报告。
- [ ] 确认首次基础检查结果已由医生查看，遗漏或异常项目已有补查、复诊或转诊安排。
- [ ] 记录体重、血压和主要不适变化。
- [ ] 准备下一次产检想确认的问题。
- [ ] 听取医生对血清学筛查、孕妇外周血胎儿游离 DNA 筛查等路径的说明，理解筛查不等于诊断。
- [ ] 预产期年龄达到或超过 35 岁，或有其他高风险因素时，尽早预约遗传咨询或产前诊断门诊；不要把早唐、无创和羊水穿刺自行当成三选一。
- [ ] 建小卡后确认社区免费中期血清学筛查和 5 次孕期健康管理的预约方式；已确认的免费服务只能在所属社区卫生院（社区卫生服务中心）办理。

## 提前准备

- 身份证
- 医保卡
- 已有检查报告
- 建档所需材料
- NT 检查预约信息
- 问题清单

## 爸爸任务

- [ ] 提醒并确认 NT 检查时间。
- [ ] 陪同检查或协助安排交通。
- [ ] 保存检查报告和预约凭证。
- [ ] 记录医生建议和后续安排。
- [ ] 协助整理建档材料。

## 完成后记录

把 NT、基础检查、建档、建小卡、生育登记、医生建议和下次产检记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：如检查时间、孕周计算或建档流程不确定，请提前联系医院确认，避免错过预约窗口。
