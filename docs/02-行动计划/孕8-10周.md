# 孕 8～10 周行动计划

## 本阶段重点

这个阶段通常早孕反应更明显，也是准备后续产检和建档的重要窗口。

核心任务是稳定就诊路径、整理资料，并分别推进社区建小卡和医院系统产检准备。

## 需要完成

- [ ] 确认后续主要产检医院。
- [ ] 了解目标医院建立围产保健手册或系统产检记录的时间、院区、预约方式和所需材料；不要只记录含义不清的“建大卡”。
- [ ] 联系居住地所属社区卫生服务中心，确认并推进建小卡。
- [ ] 通过“浙里办”办理或检查生育登记状态。
- [ ] 保存已有检查报告。
- [ ] 对照首次产检基础检查，确认首次妊娠风险筛查、问诊、体格检查和基础化验怎样安排。
- [ ] 记录早孕反应、饮食、睡眠和体重变化。
- [ ] 复盘饮食安全：肉蛋鱼虾熟透、蔬果洗净、奶制品正规、补充剂不自行加量。
- [ ] 继续记录孕吐触发因素、饮水和排尿情况；严重影响进食饮水时及时咨询医生。
- [ ] 按医生建议安排营养补充和复查。
- [ ] 了解 11～13+6 周 NT 超声筛查的知情选择和预约要求。
- [ ] 如准备使用妊娠油或其他身体护理产品，先核对全成分表并小面积试用；没有皮肤干燥等不适时，不需要为了防纹提前使用。
- [ ] 如处于流感疫苗接种季，向产科或接种医生确认孕妇适用产品和接种条件；爸爸及预计照护 6 月龄以下婴儿的家庭成员同步核对当季接种安排。
- [ ] 孕前未做口腔检查，或已有牙龈出血、牙痛等问题时，预约正规口腔科评估并主动说明孕周。

## 提前准备

- 身份证
- 医保卡
- 已有检查报告
- 目标医院预约渠道
- 建档材料清单
- 医院所称事项的正式名称和完成标志
- 社区建小卡材料：前期检查报告、夫妻双方身份证；夫妻一方为受理地本地户籍时，再带该方户口本
- 后续想确认的问题

## 爸爸任务

- [ ] 查询并记录目标医院系统产检流程、科室、院区和完成标志。
- [ ] 电话确认社区建小卡流程、材料和检查前准备。
- [ ] 协助预约后续产检或 NT 检查。
- [ ] 帮忙保存电子版和纸质检查资料。
- [ ] 关注孕妇饮食和休息，减少不必要奔波。
- [ ] 准备一个共享记录位置，用于保存报告、待办和问题。

## 完成后记录

把目标医院、建档要求、社区、建小卡、生育登记、NT 预约、下次产检和待补材料记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 就医提醒：如出现明显不适、异常出血、持续疼痛或其他让你担心的情况，请及时联系医生或前往医院。
