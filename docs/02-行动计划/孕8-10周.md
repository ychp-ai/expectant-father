# 孕 8～10 周行动计划

## 本阶段重点

这个阶段通常早孕反应更明显，也是准备后续产检和建档的重要窗口。

核心任务是稳定就诊路径、整理资料，并提前了解所在医院的建档要求。

## 需要完成

- [ ] 确认后续主要产检医院。
- [ ] 了解目标医院建档时间、预约方式和所需材料。
- [ ] 保存已有检查报告。
- [ ] 记录早孕反应、饮食、睡眠和体重变化。
- [ ] 按医生建议安排营养补充和复查。
- [ ] 了解 11～13 周 NT 检查的预约要求。

## 提前准备

- 身份证
- 医保卡
- 已有检查报告
- 目标医院预约渠道
- 建档材料清单
- 后续想确认的问题

## 爸爸任务

- [ ] 查询并记录目标医院建档流程。
- [ ] 协助预约后续产检或 NT 检查。
- [ ] 帮忙保存电子版和纸质检查资料。
- [ ] 关注孕妇饮食和休息，减少不必要奔波。
- [ ] 准备一个共享记录位置，用于保存报告、待办和问题。

## 风险提醒

> 就医提醒：如出现明显不适、异常出血、持续疼痛或其他让你担心的情况，请及时联系医生或前往医院。
