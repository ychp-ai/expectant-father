# 孕 5～7 周行动计划

## 本阶段重点

这个阶段的核心是确认怀孕，并在医生指导下确认孕囊位置和早期发育情况。

重点不是一次性准备所有东西，而是先把基础信息、就诊资料和首次产检安排理清楚。

## 需要完成

- [ ] 使用早孕试纸或到医院进行初步确认。
- [ ] 记录末次月经第一天。
- [ ] 整理既往病史、过敏史、用药史和手术史。
- [ ] 整理夫妻双方家族史、遗传病史和可能影响妊娠的职业或感染暴露信息。
- [ ] 选择后续产检医院或先就近就诊。
- [ ] 根据实际住址确认所属社区卫生服务中心，并电话了解建小卡要求。
- [ ] 查询杭州职工医保和生育保险参保状态是否正常。
- [ ] 根据医生建议安排早期超声或抽血检查。
- [ ] 开始记录体重、血压和不适症状。
- [ ] 检查当前饮食是否避开酒精、生食、未熟透肉蛋鱼虾和来源不明的补充剂。
- [ ] 如出现孕吐，记录触发因素、喝水情况、呕吐次数和是否出现就医信号。

## 提前准备

- 身份证
- 医保卡
- 末次月经日期
- 既往检查报告
- 近期用药清单
- 想咨询医生的问题

## 爸爸任务

- [ ] 陪同确认怀孕或第一次就诊。
- [ ] 帮忙整理证件和既往资料。
- [ ] 记录医生交代的复查时间。
- [ ] 联系社区，记录建小卡的时间、材料和是否需要空腹等要求。
- [ ] 分担家务，帮助孕妇保证休息。
- [ ] 了解孕早期常见不适，但避免过度焦虑。

## 完成后记录

把孕周、末次月经、就诊信息、医生建议、社区归属、建小卡和医保状态记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 就医提醒：如出现阴道出血、持续或明显腹痛、晕厥、剧烈头痛等情况，请及时联系医生或前往医院。
