# 孕 5～7 周行动计划

## 本阶段重点

这个阶段的核心是确认怀孕，并在医生指导下确认孕囊位置和早期发育情况。

重点不是一次性准备所有东西，而是先把基础信息、就诊资料和首次产检安排理清楚。

## 需要完成

- [ ] 使用早孕试纸或到医院进行初步确认。
- [ ] 记录末次月经第一天。
- [ ] 整理既往病史、过敏史、用药史和手术史。
- [ ] 选择后续产检医院或先就近就诊。
- [ ] 根据医生建议安排早期超声或抽血检查。
- [ ] 开始记录体重、血压和不适症状。

## 提前准备

- 身份证
- 医保卡
- 末次月经日期
- 既往检查报告
- 近期用药清单
- 想咨询医生的问题

## 爸爸任务

- [ ] 陪同确认怀孕或第一次就诊。
- [ ] 帮忙整理证件和既往资料。
- [ ] 记录医生交代的复查时间。
- [ ] 分担家务，帮助孕妇保证休息。
- [ ] 了解孕早期常见不适，但避免过度焦虑。

- 确认怀孕日期：
- 末次月经日期：
- 预计孕周：
- 医院/医生：
- 医生建议：
- 下次复查时间：

## 风险提醒

> 就医提醒：如出现阴道出血、持续或明显腹痛、晕厥、剧烈头痛等情况，请及时联系医生或前往医院。
