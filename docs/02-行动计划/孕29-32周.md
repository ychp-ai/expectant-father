# 孕 29～32 周行动计划

## 本阶段重点

这个阶段开始进入孕晚期节奏，产检会逐渐更频繁，重点是关注胎儿生长情况、孕妇身体负担变化，并提前准备待产相关事项。

此时不需要一次性完成所有准备，但建议把待产包、医院路线、宝宝用品和陪产安排逐步梳理起来。

## 需要完成

- [ ] 确认本阶段产检时间。
- [ ] 根据医生安排完成胎儿生长评估或相关检查。
- [ ] 确认孕晚期血尿检查及一次肝肾功能复查怎样安排。
- [ ] 了解胎心监护通常从什么时候开始。
- [ ] 持续记录体重、血压和胎动。
- [ ] 建立待产包清单并开始分批准备。
- [ ] 初步确认生产医院路线、停车和夜间出行方案。
- [ ] 学习临产信号和入院准备。
- [ ] 如继续使用妊娠油，沿用已经耐受的产品并注意地面防滑；严重、夜间加重或手掌脚底瘙痒时停止自行处理并联系产科。

## 提前预约

- [ ] 孕晚期常规产检。
- [ ] 胎心监护或医生建议的后续检查。

## 提前准备

- 产检手册或建档资料
- 已有检查报告
- 胎动记录
- 待产包清单
- 医院地址和交通路线
- 紧急联系人清单

## 爸爸任务

- [ ] 负责整理待产包初版清单。
- [ ] 熟悉去医院路线，确认停车和夜间入口。
- [ ] 保存医院电话和紧急联系人。
- [ ] 和孕妇一起学习临产信号。
- [ ] 继续协助记录胎动、体重和血压。
- [ ] 分担家务，减少孕妇体力消耗。

## 完成后记录

把本阶段产检、孕晚期复查、胎心监护安排、待产包和医院路线记录到个人资料仓库的当前记录页，不要填写在本通用页面。

## 风险提醒

> 提醒：孕晚期如出现明显不适、胎动明显变化、规律宫缩、破水或其他让你担心的情况，请及时联系医生或前往医院。
