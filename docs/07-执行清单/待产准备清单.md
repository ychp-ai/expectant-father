# 待产准备清单

## 资料准备

- [ ] 身份证件已放入资料袋。
- [ ] 卡片和支付工具已准备。
- [ ] 孕期档案已整理。
- [ ] 近期报告已整理。
- [ ] 医院要求的材料已确认。
- [ ] 重要资料已拍照或扫描备份。

## 物品准备

- [ ] 待产包已完成第一轮打包。
- [ ] 妈妈用品已分类。
- [ ] 宝宝用品已分类。
- [ ] 陪护用品已准备。
- [ ] 充电器和移动电源已准备。
- [ ] 常用物品放在容易拿的位置。

## 到院准备

- [ ] 医院地址已保存。
- [ ] 入口位置已确认。
- [ ] 停车方案已确认。
- [ ] 夜间路线已确认。
- [ ] 应急联系人已保存。
- [ ] 家人通知顺序已约定。

## 家庭准备

- [ ] 回家空间已整理。
- [ ] 第一周消耗品已准备。
- [ ] 家务分工已确认。
- [ ] 餐食或采购安排已确认。
- [ ] 探视规则已初步沟通。

## 每周检查

- [ ] 检查资料袋。
- [ ] 检查待产包。
- [ ] 检查路线和联系人。
- [ ] 更新未完成事项。
