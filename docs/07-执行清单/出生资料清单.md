# 出生资料清单

## 基本信息

- [ ] 出生日期、时间和地点已记录。
- [ ] 宝宝姓名或待确认状态已记录。
- [ ] 医院名称和相关科室联系方式已记录。
- [ ] 基础出生信息已由家人核对。

## 文件归档

- [ ] 医院提供的出生相关文件已保存。
- [ ] 住院和出院材料已归档。
- [ ] 费用票据和清单已归档。
- [ ] 重要文件已按需要复印或扫描。

## 办事登记

- [ ] 已打开浙江政务服务当次“出生一件事”页面并核对适用条件。
- [ ] 出生医学证明要求已确认。
- [ ] 预防接种证或电子接种档案已经建立，首剂疫苗记录和下一次接种安排已保存。
- [ ] 宝宝保障事项已查询并登记。
- [ ] 户籍事项已查询并登记。
- [ ] 新生儿医保参保登记、缴费和医保码或社保卡后续动作已分别确认；符合杭州条件时已注意出生后 3 个月内的参保缴费窗口。
- [ ] 国家育儿补贴、杭州三孩补助和 3 岁以下婴幼儿照护个税扣除已分别核对，没有误认为联办后自动完成。
- [ ] 每项办理渠道、材料、期限和负责人已记录。
- [ ] 回执、编号和后续提醒已保存。
