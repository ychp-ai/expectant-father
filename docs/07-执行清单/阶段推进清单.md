# 阶段推进清单

## 孕早期

- [ ] 确认怀孕相关信息已记录。
- [ ] 首次产检或建档安排已确认。
- [ ] 证件、报告和资料已集中归档。
- [ ] 产检日期已同步到日历。
- [ ] 爸爸已了解当前阶段需要承担的任务。
- [ ] 家庭已确认近期最重要的待办事项。
- [ ] 女方已了解产检和孕期劳动保护入口，男方已确认单位护理假入口。

## 孕中期

- [ ] 行动计划已更新到当前孕周阶段。
- [ ] 重要检查预约已确认。
- [ ] 既往报告已整理。
- [ ] 家庭分工已讨论。
- [ ] 物资准备清单已开始维护。
- [ ] 爸爸已开始学习基础照护知识。
- [ ] 夫妻已分别确认产假、护理假、育儿假和生育津贴经办流程。

## 孕晚期

- [ ] 待产包已开始准备。
- [ ] 到院路线和入口已确认。
- [ ] 证件、资料和报告已整理。
- [ ] 应急联系人已确认。
- [ ] 家庭分工和支持人员已确认。
- [ ] 出生资料登记和办理分工已初步确认。
- [ ] 女方 158 天或 188 天产假、男方 15 天护理假及双方育儿假入口已确认。

## 临产前

- [ ] 待产包已放在固定位置。
- [ ] 交通方案已确认。
- [ ] 医院联系方式已保存。
- [ ] 入院资料已检查。
- [ ] 家人通知顺序已约定。
- [ ] 爸爸已熟悉临产陪伴指南。

## 出生后

- [ ] 出生资料已集中保存。
- [ ] 出生医学证明、户籍、预防接种证或接种档案已逐项确认。
- [ ] 符合杭州参保条件时，新生儿基本医保已在出生后 3 个月内完成参保并缴费。
- [ ] 医院要求保留的出院文件和费用材料已归档。
- [ ] 每项办理结果、回执位置和下一步已记录到私人位置。
- [ ] 生育津贴、杭州现行孕产补助、育儿补助、三孩补助和个税扣除已按各自条件与期限单独核对。
- [ ] 双方育儿假周年提醒和女方复工哺乳时间已确认。
- [ ] 符合多子女家庭条件且有需求时，公积金贷款或租房提取优惠已核对。
