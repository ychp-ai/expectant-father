# 阶段推进清单

## 孕早期

- [ ] 确认怀孕相关信息已记录。
- [ ] 首次产检或建档安排已确认。
- [ ] 证件、报告和资料已集中归档。
- [ ] 产检日期已同步到日历。
- [ ] 爸爸已了解当前阶段需要承担的任务。
- [ ] 家庭已确认近期最重要的待办事项。

## 孕中期

- [ ] 行动计划已更新到当前孕周阶段。
- [ ] 重要检查预约已确认。
- [ ] 既往报告已整理。
- [ ] 家庭分工已讨论。
- [ ] 物资准备清单已开始维护。
- [ ] 爸爸已开始学习基础照护知识。

## 孕晚期

- [ ] 待产包已开始准备。
- [ ] 到院路线和入口已确认。
- [ ] 证件、资料和报告已整理。
- [ ] 应急联系人已确认。
- [ ] 家庭分工和支持人员已确认。
- [ ] 回家后的第一周安排已初步规划。

## 临产前

- [ ] 待产包已放在固定位置。
- [ ] 交通方案已确认。
- [ ] 医院联系方式已保存。
- [ ] 入院资料已检查。
- [ ] 家人通知顺序已约定。
- [ ] 爸爸已熟悉临产陪伴指南。

## 出生后

- [ ] 出生资料已集中保存。
- [ ] 妈妈恢复支持事项已安排。
- [ ] 宝宝基础用品已到位。
- [ ] 后续办事事项已列入清单。
- [ ] 家庭探视和沟通规则已确认。
- [ ] 每日照护分工已执行。
