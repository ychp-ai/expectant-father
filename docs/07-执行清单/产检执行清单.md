# 产检执行清单

## 产检前

- [ ] 确认预约时间。
- [ ] 确认检查地点。
- [ ] 确认是否有特殊准备要求。
- [ ] 准备证件和卡片。
- [ ] 准备孕期档案。
- [ ] 准备既往检查报告。
- [ ] 整理想问医生的问题。
- [ ] 提前规划交通和停车。

## 产检当天

- [ ] 提前出发。
- [ ] 到院后确认科室或窗口。
- [ ] 保存缴费记录。
- [ ] 检查后领取或确认报告领取方式。
- [ ] 记录医生建议。
- [ ] 确认下一次产检时间。

## 产检后

- [ ] 报告拍照或扫描。
- [ ] 纸质报告归档。
- [ ] 更新家庭日历。
- [ ] 更新行动计划完成情况。
- [ ] 记录需要复查或补充的事项。
- [ ] 和妈妈复盘本次产检感受。

## 爸爸负责

- [ ] 预约提醒。
- [ ] 资料整理。
- [ ] 路线安排。
- [ ] 排队和缴费协助。
- [ ] 报告归档。
- [ ] 后续事项提醒。

## 记录模板

- 日期：
- 孕周：
- 项目：
- 地点：
- 结果摘要：
- 医生建议：
- 下一步：
