# 执行清单

本模块把已有文档中的事项整理成可勾选清单，方便家庭按阶段推进。

## 使用方式

- 每周固定检查一次当前阶段清单。
- 每次产检前后更新产检清单。
- 孕晚期开始重点维护待产、到院和回家清单。
- 出生后继续维护资料和后续事项清单。
- 清单由爸爸负责维护，妈妈负责确认身体感受和个人偏好。

## 清单导航

| 清单 | 用途 | 文档 |
|---|---|---|
| 阶段推进清单 | 按孕期阶段推进家庭任务 | [阶段推进清单](./阶段推进清单.md) |
| 产检执行清单 | 产检前、当天、产检后的通用流程 | [产检执行清单](./产检执行清单.md) |
| 待产准备清单 | 孕晚期到临产前的准备事项 | [待产准备清单](./待产准备清单.md) |
| 出生后事项清单 | 出生后资料、照护和家庭分工 | [出生后事项清单](./出生后事项清单.md) |

## 状态标记建议

- `[ ]` 未开始
- `[x]` 已完成
- `进行中` 正在处理
- `待确认` 需要咨询医院、医生、社区或单位
- `不适用` 当前家庭不需要
