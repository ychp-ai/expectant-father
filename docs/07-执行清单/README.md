# 执行清单

## 地区专项

- [杭州孕期必办事项](./杭州孕期必办事项.md)：面向杭州常住孕产妇场景的社区、医院、政务、医保、单位、补助、分娩前和出生后必要手续总入口。

本模块把已有文档中的事项整理成可勾选清单，方便家庭按阶段推进。

## 使用方式

- 每周固定检查一次当前阶段清单。
- 每次产检前后更新产检清单。
- 孕晚期开始重点维护待产、到院和回家清单。
- 出生后继续维护资料和后续事项清单。
- 清单由爸爸负责维护，妈妈负责确认身体感受和个人偏好。

## 状态标记建议

- `[ ]` 未开始
- `[x]` 已完成
- `进行中` 正在处理
- `待确认` 需要咨询医院、医生、社区或单位
- `不适用` 当前家庭不需要
