# 待产包 Checklist

## 证件资料

- [ ] 身份证
- [ ] 医保卡
- [ ] 孕妇保健手册
- [ ] 检查报告
- [ ] 银行卡或支付工具

## 妈妈用品

- [ ] 哺乳内衣
- [ ] 一次性内裤
- [ ] 产褥垫
- [ ] 卫生巾
- [ ] 洗漱用品
- [ ] 拖鞋
- [ ] 外套或出院衣物

## 宝宝用品

- [ ] 新生儿衣物
- [ ] 包被
- [ ] 帽子
- [ ] 纸尿裤
- [ ] 湿巾
- [ ] 小毛巾

## 爸爸用品

- [ ] 充电器
- [ ] 水杯
- [ ] 零食
- [ ] 换洗衣物
- [ ] 医院路线和停车方案

> 提醒：不同医院对待产包要求不同，请以医院清单为准。
