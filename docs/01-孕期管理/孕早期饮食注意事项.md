# 孕早期饮食注意事项

本页用于当前孕早期的家庭饮食安排。目标是保证基本营养、减少孕吐诱发、降低食源性风险；不用于替代医生或营养门诊的个体化建议。

## 先记住几条原则

- 不需要“吃两个人的量”，先保证能规律进食和饮水。
- 每天尽量有主食、蛋白质、蔬菜水果和奶制品或替代来源。
- 孕吐明显时，把“吃得完美”降级为“能吃、能喝、能留住”。
- 补充剂和药物按医生建议使用，不自行加量、停用或叠加。
- 任何饮食建议遇到医生针对个人情况的安排时，以医生安排为准。

## 当前可以这样安排

- 主食：米饭、面条、馒头、面包、土豆、燕麦等都可以，孕吐时优先选清淡、容易接受的。
- 蛋白质：鸡蛋、鱼虾、禽肉、瘦肉、豆制品、豆类和坚果可轮换，但肉、蛋、鱼虾都要充分加热。
- 蔬菜水果：每天尽量吃不同种类，生吃前洗净；预切水果和即食沙拉要注意冷藏和保质期。
- 奶制品：优先选择正规渠道的巴氏消毒或灭菌奶、酸奶、奶酪；不吃未消毒奶制品。
- 饮水：少量多次，孕吐时比追求饭量更重要；尿色变深或尿量明显减少要警惕。
- 加餐：可以准备苏打饼干、吐司、坚果、酸奶、水果、小份主食，避免长时间空腹。

## 孕吐明显时

- 少量多餐，把三餐拆成 5～6 次小份。
- 起床前先吃几口能接受的干粮，再慢慢起身。
- 避开油烟、重味、过甜、过油和让人反胃的食物。
- 热食气味刺激时，可以换成温凉、味道轻的食物。
- 不强迫吃“别人说有营养但当下吃不下”的东西。
- 连续吃不下、喝不进、尿少、头晕或体重下降时，及时联系医生。

孕吐处理细节见[孕吐应对](./孕吐应对.md)。

## 需要避免或谨慎

- 不喝酒。
- 咖啡、浓茶、可乐、能量饮料和巧克力都可能含咖啡因；如摄入咖啡因，应控制总量，并把医生建议放在第一位。
- 不吃生肉、未熟透肉类、半熟蛋、生鱼片、生贝类和未充分加热的冷食。
- 不吃未巴氏消毒的奶、奶制品或来源不明的软奶酪。
- 避免肝脏、肝制品、鱼肝油和含维生素 A 视黄醇的补充剂，除非医生明确要求。
- 鱼类选择低汞、熟透的种类；避免高汞大型鱼类和来源不明的野生鱼。
- 少吃高糖、高油和高盐零食，不把奶茶、甜饮料当作补水。
- 草本茶、保健品、代餐粉、网红补剂和所谓“安胎食疗”先问医生，不自行尝试。

## 爸爸可以负责

- 每天准备 2～3 种小份、清淡、容易拿取的食物。
- 做饭时控制油烟和气味，必要时先开窗通风。
- 记录哪些食物能吃、哪些味道会诱发孕吐。
- 帮忙查看食品是否过期、是否需要冷藏、肉蛋鱼虾是否熟透。
- 产检前整理要问医生的问题：叶酸、维生素 D、铁剂、孕吐影响进食、咖啡因和鱼类选择。
