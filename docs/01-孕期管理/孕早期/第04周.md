# 第04周（孕早期）

## 本周母体与胎儿状态

### 孕妇状态
- 预计月经可能没有按时出现，也可能尚无明显症状；是否有早孕反应不能单独用于判断怀孕。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、晕厥，或严重呕吐导致无法进食饮水，请及时联系医生或前往医院。

### 胎儿状态

- 着床前后，囊胚内部的细胞逐步形成胚胎，外层细胞参与形成胎盘。
- 羊膜囊和卵黄囊等早期支持结构正在建立；胚胎仍很微小，此时不宜用通用尺寸与超声报告逐项比对。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-001；具体来源见文末。
