# 第08周（孕早期）

## 本周母体与胎儿状态

### 孕妇状态
- 可进入建档与基础检查阶段，谨慎用药。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、晕厥，或严重呕吐导致无法进食饮水，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头臀长（头顶到臀部）约 1.6 厘米，仅用于了解大致大小，不是正常值上下限。
- 头部和躯干逐步舒展，手臂与腿继续延长，外形正在由早期弯曲形态向更清楚的人体轮廓变化。
- 眼、外耳和鼻唇部轮廓继续细化，手指开始形成；器官结构形成仍不等于功能已经成熟。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-001；具体来源见文末。
