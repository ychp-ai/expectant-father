# 第02周（孕早期）

## 本周母体与胎儿状态

### 孕妇状态
- 按常见 28 天周期推算，排卵可能发生在本周后段，但实际时间会随周期长度和个体情况变化。
- 本周通常仍无法通过早孕试纸可靠确认怀孕，不要用一次阴性结果判断本周期一定没有受孕。

### 胎儿状态

- 按常见月经周期，身体正在为排卵和受精做准备；此时通常尚无可观察的胚胎。
- 受精发生时间随排卵而变化，不能把本页周数当成固定受精日期。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：MAYO-DEVELOP-001；具体来源见文末。
