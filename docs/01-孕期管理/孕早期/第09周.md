# 第09周（孕早期）

## 本周母体与胎儿状态

### 孕妇状态
- 孕吐可能持续，注意电解质与营养摄入平衡。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、晕厥，或严重呕吐导致无法进食饮水，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头臀长（头顶到臀部）约 2.2 厘米，仅用于了解大致大小，不是正常值上下限。
- 眼睑、口部和舌的轮廓更清楚，手足细节继续分化。
- 心、脑、肺、肾和消化道等主要器官仍在发育，骨骼也开始形成。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001；具体来源见文末。
