# 第07周（孕早期）

## 本周母体与胎儿状态

### 孕妇状态
- 疲劳与情绪波动可能明显，需保证睡眠与补水。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、晕厥，或严重呕吐导致无法进食饮水，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头臀长（头顶到臀部）约 1 厘米，仅用于了解大致大小，不是正常值上下限。
- 头部相对身体较大，脑部快速发育，面部和眼睑的早期轮廓逐渐出现。
- 肢芽继续延长，末端逐步形成手、足的雏形，肢体内的软骨结构也在发展。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001；具体来源见文末。
