# 孕期管理

本模块按孕周整理第 1～40 周的身体变化、阶段重点和每周记录，帮助家庭快速找到当前孕周需要关注的事项。

> 提醒：孕周文档用于家庭管理和沟通，不能替代医生诊疗意见。检查安排和身体异常请以产科医生、医院及当地要求为准。

## 按阶段进入

| 阶段 | 孕周 | 主要关注 | 入口 |
|---|---|---|---|
| 孕早期 | 第 1～12 周 | 确认怀孕、首次产检、建档和早期筛查 | [第01周](./孕早期/第01周.md) |
| 孕中期 | 第 13～27 周 | 中期筛查、系统超声、糖代谢检查和日常记录 | [第13周](./孕中期/第13周.md) |
| 孕晚期 | 第 28～40 周 | 胎动与血压观察、待产准备和临产安排 | [第28周](./孕晚期/第28周.md) |

## 如何阅读宝宝每周状态

从[完整孕周目录](../../README.md#孕周目录)选择对应周数，每页「胎儿状态」提供大小参照、外形或器官变化和活动特点。孕 1～4 周侧重计时、受精和着床，不强行提供尺寸。

- **孕周与受精时间不同**：医学孕周从末次月经第一天起算，通常比受精后时间多约两周。页面描述本孕周前后的过程，不是每周末必须达成的清单；个人孕周以医生采用的记录为准。
- **尺寸只是示意**：逐周长度统一采用 NHS 对应周的近似示例，未列体重正常值。5～19 周写头臀长，20 周起写头踵长，因此 19 到 20 周的数字不能直接相减比较生长速度；科普全长也不能直接与超声报告中的头围、腹围或股骨长相比。
- **形成不等于成熟**：有器官雏形、呼吸样运动或开始产生肺表面活性物质，都不能证明器官已经能独立完成出生后的功能。不同权威资料对早期细节、睁眼等时间存在差异，使用“逐步”“前后”等表述。
- **胎动有自己的节奏**：通常在孕 16～24 周首次感知，初次怀孕可能到 20 周后才感觉到；24 周仍从未感觉到，应联系产科。已熟悉的胎动明显减少、消失或模式改变时，立即联系产科，不等到次日、不用家用胎心仪自行排除异常。临近分娩也应继续有胎动，具体记录方法遵从产科指导。
- **足月也有成熟度差异**：国际细分把 37～38+6 周称为早期足月，39～40+6 周称为完全足月。37 周后仍有重要器官发育；这些术语不决定个人分娩时机。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-001、MAYO-DEVELOP-002、MAYO-DEVELOP-003、NHS-MOVE-001、NICHD-TERM-001；详见[项目参考资料](../../references/README.md)。专项复核：2026-09-18。

## 使用方式

1. 打开当前孕周文档，查看本周状态和重点事项。
2. 进入对应阶段的行动计划，确认需要预约、准备和记录的任务。
3. 根据医院安排查阅产检指南，不自行根据文档判断检查结果。
4. 使用[孕期记录模板](../08-记录模板/孕期记录.md)，把体重、血压、身体感受、已完成事项和下周待办填写到个人资料仓库的当前记录页或其他私人记录工具；不要直接在通用孕周文档中填写。
