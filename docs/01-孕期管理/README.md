# 孕期管理

本模块按孕周整理第 1～40 周的身体变化、阶段重点和每周记录，帮助家庭快速找到当前孕周需要关注的事项。

> 提醒：孕周文档用于家庭管理和沟通，不能替代医生诊疗意见。检查安排和身体异常请以产科医生、医院及当地要求为准。

## 按阶段进入

| 阶段 | 孕周 | 主要关注 | 入口 |
|---|---|---|---|
| 孕早期 | 第 1～12 周 | 确认怀孕、首次产检、建档和早期筛查 | [第01周](./孕早期/第01周.md) |
| 孕中期 | 第 13～27 周 | 中期筛查、系统超声、糖代谢检查和日常记录 | [第13周](./孕中期/第13周.md) |
| 孕晚期 | 第 28～40 周 | 胎动与血压观察、待产准备和临产安排 | [第28周](./孕晚期/第28周.md) |

## 使用方式

1. 打开当前孕周文档，查看本周状态和重点事项。
2. 进入对应阶段的行动计划，确认需要预约、准备和记录的任务。
3. 根据医院安排查阅产检指南，不自行根据文档判断检查结果。
4. 使用[孕期记录模板](../08-记录模板/孕期记录.md)，把体重、血压、身体感受、已完成事项和下周待办填写到个人资料仓库的当前记录页或其他私人记录工具；不要直接在通用孕周文档中填写。
