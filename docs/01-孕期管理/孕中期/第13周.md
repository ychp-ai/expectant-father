# 第13周（孕中期）

## 本周母体与胎儿状态

### 孕妇状态
- 孕吐多逐步缓解，体力和食欲一般较前期改善。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、高热、严重头痛或视物异常，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头臀长（头顶到臀部）约 7.4 厘米，仅用于了解大致大小，不是正常值上下限。
- 肢体活动逐渐丰富，有时可出现吸吮拇指的动作，为吸吮反射的发展做准备。
- 骨骼开始进一步硬化，尤其是颅骨及四肢长骨；皮肤仍较薄。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-002；具体来源见文末。
