# 第26周（孕中期）

## 本周母体与胎儿状态

### 孕妇状态
- 继续监测体重、血压，警惕异常水肿。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、严重头痛或视物异常，或已感知的胎动模式明显变化，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 35.6 厘米，仅用于了解大致大小，不是正常值上下限。
- 眼部结构、眉毛和睫毛继续完善，眼睑在这一阶段前后逐步具备睁开的能力。
- 不同资料把开始睁眼描述在约 26～28 周，不把它写成每个宝宝必须在本周完成的里程碑。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-002；具体来源见文末。
