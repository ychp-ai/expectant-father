# 第25周（孕中期）

## 本周母体与胎儿状态

### 孕妇状态
- 腹部继续增大，注意姿势和腰背保护。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、严重头痛或视物异常，或已感知的胎动模式明显变化，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 34.6 厘米，仅用于了解大致大小，不是正常值上下限。
- 活动较活跃，有时可出现打嗝样的节律性动作，也可能对声音作出动作反应。
- 宝宝持续排尿，尿液已是羊水的重要组成部分；羊水提供缓冲和相对稳定的环境。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001；具体来源见文末。
