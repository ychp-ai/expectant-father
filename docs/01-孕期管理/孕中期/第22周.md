# 第22周（孕中期）

## 本周母体与胎儿状态

### 孕妇状态
- 关注下肢水肿和便秘，规律活动与补水。
- 就医提醒：如有阴道出血、持续或剧烈腹痛、严重头痛或视物异常，或已感知的胎动模式明显变化，请及时联系医生或前往医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 27.8 厘米，仅用于了解大致大小，不是正常值上下限。
- 肺部仍在发育，可出现呼吸样运动；这种动作不代表已能在出生后独立呼吸。
- 会吞咽少量羊水，味蕾也在发展，消化道继续为出生后的进食做准备。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001；具体来源见文末。
