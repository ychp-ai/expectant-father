# 燕窝蒸制教程

本页整理家庭提供的小罐分装蒸燕窝做法，供选择制作时查阅。容量、水位、20 分钟和外观描述来自家庭经验，不作为统一烹饪标准或孕期营养推荐。

## 准备材料和器具

- [ ] 燕窝、饮用水、清洁的挑杂工具。
- [ ] 50～100 ml 的耐高温透明玻璃小罐，便于分装和观察。
- [ ] 蒸锅、蒸屉、隔热手套或取罐夹。
- [ ] 使用前确认罐身完好，且说明书明确适用于蒸制；罐盖、密封圈能否一起加热及如何盖合，要分别核对。

> 加盖方式待按实际罐型确认：家庭原做法是“拧紧盖子”。目前未提供具体罐型，不能仅凭“耐高温玻璃”认定可以密封蒸制。说明书未明确允许时，不拧紧密封加热，改用明确支持蒸制的容器，并按其说明盖合或留出排气口。

## 操作步骤

1. **泡发、挑杂**：按燕窝包装说明泡发，泡发后用清洁工具挑出杂质，再清洗干净。原记录未提供泡发时长，按实际产品说明执行。
2. **分装**：将处理好的燕窝分装到洗净的小罐中。
3. **加水**：加入适量饮用水。家庭经验水位为“比罐口底部再低一点”，即低于罐口下沿、留出顶部空间，不加满；具体以容器允许装量为限。
4. **盖合**：按已确认的容器说明处理罐盖；只有明确允许相应加盖蒸制方式时，才采用该方式。
5. **烧水、上屉**：锅内加入足够蒸制用的水，烧开后再放上蒸屉，将罐子放稳，盖上锅盖。操作时避开热蒸汽。
6. **蒸制**：家庭做法为水开上屉后蒸约 **20 分钟**。燕窝种类、泡发程度、装量和火力不同，所需时间可能不同；产品说明有要求时优先按说明执行。
7. **观察、取出**：透过透明罐身观察，家庭描述的状态是燕窝“像有气泡一样”。此现象仅作外观参考，不能单凭气泡或满 20 分钟判定已充分加热。完成蒸制后关火，待蒸汽散去，用隔热工具取罐，放到耐热垫上。

## 食用安排（家庭经验）

- **频率**：隔天吃一次，即吃一天、间隔一天。
- **时间**：空腹吃。

以上为家庭提供的食用安排，仅作做法记录，不作为统一的孕期营养建议，也不表示空腹食用有额外益处。

## 食品卫生

- 操作前洗手，清洁器具，使用安全的饮用水和原料。
- 食物需充分加热；分装后的熟食避免被生食或未清洁工具再次污染。
- 做好后及时食用；需要留存时按食品安全原则及时冷藏，不把这套家庭蒸制步骤当作可常温保存的罐头灭菌工艺。
