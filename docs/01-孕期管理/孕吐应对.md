# 孕吐应对

本页用于孕早期出现恶心、呕吐、气味敏感和食欲下降时的家庭记录与支持。它不能替代医生诊断，也不用于判断检查结果或自行选择药物。

## 先判断是否需要联系医生

出现以下情况时，不要只按普通孕吐处理，应及时联系产科医生、就诊医院或当地急诊渠道：

- 24 小时无法留住食物或水。
- 尿液颜色很深，或超过 8 小时没有排尿。
- 站立时明显头晕、虚弱或快要晕倒。
- 腹痛、发热或其他不像普通孕吐的症状。
- 呕血。
- 体重下降。
- 呕吐严重到无法服用医生开的口服药或无法喝水。
- 恶心呕吐已经明显影响日常活动、睡眠或情绪。

孕吐可能在一天中任何时候发生。轻中度孕吐常见，但严重呕吐可能导致脱水、营养不足或需要医院补液，不能硬扛到下次产检。

## 可以先尝试的生活调整

- 少量多餐，不空腹，也不要一次吃太饱。
- 起床前先吃少量干吐司、苏打饼干或其他能接受的清淡食物。
- 优先选择容易消化、低脂、气味轻的食物，如米饭、面条、面包、土豆、饼干。
- 暂时避开油腻、辛辣、高脂和气味重的食物。
- 热食气味刺激时，可尝试温度低一点的食物。
- 小口频繁喝水或无咖啡因饮品，重点是避免脱水。
- 保证休息，疲劳可能加重恶心。
- 记录触发因素，如油烟、香水、牙膏味、某类食物或乘车。
- 呕吐后漱口，减少胃酸对牙齿的刺激。

姜类食物、姜茶或腕部按压手环对部分人可能有帮助，但效果因人而异。姜补充剂、维生素 B6、多西拉敏或其他止吐药物，都应先咨询产科医生或药师，不自行购买和叠加使用。

## 饮食记录

每天只记录对决策有用的信息，不追求精确到每一口：

- 今天能接受的食物：
- 今天明显诱发恶心的食物或气味：
- 今天喝水情况：正常 / 偏少 / 很少
- 今天排尿情况：正常 / 减少 / 颜色很深
- 今天呕吐次数：
- 今天体重变化：
- 是否影响睡眠或上班：
- 是否需要咨询医生：是 / 否

如果连续多日进食饮水明显减少，或记录显示尿量减少、体重下降、头晕加重，应尽快联系医生。

## 爸爸可以负责

- 在床边准备小饼干、温水、纸巾和漱口用品。
- 做饭时减少油烟和重味，必要时让妈妈远离厨房。
- 把能吃的食物分成小份，方便少量多次进食。
- 每天简单记录呕吐次数、喝水量、尿色、体重变化和触发因素。
- 提醒休息并分担家务，不用“别人都这样”来压低妈妈感受。
- 出现就医信号时，直接协助联系医院或安排就诊。

## 和产检衔接

下次产检或复诊前，可以把以下问题整理给医生：

- 当前呕吐频率是否需要处理。
- 是否需要调整孕期维生素或含铁补充剂的服用时间。
- 是否可以使用维生素 B6、姜制品或止吐药。
- 哪些情况需要提前来院，而不是等到预约日期。
- 如果无法正常进食饮水，是否需要补液或进一步检查。
