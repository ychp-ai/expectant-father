# 第32周（孕晚期）

## 本周母体与胎儿状态

### 孕妇状态
- 建议开始打包待产物资，分证件与生活用品。
- 就医提醒：如有胎动明显减少或改变、阴道出血、阴道流液、严重头痛或视物异常，请及时联系产科医生或前往医院；未满 37 周出现规律宫缩也应及时联系医院。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 42.4 厘米，仅用于了解大致大小，不是正常值上下限。
- 身体轮廓已较完整，仍要继续积累体重和脂肪，不能把外形完整等同于各器官成熟。
- 脚趾甲已可见，覆盖皮肤的细软胎毛开始逐渐脱落。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-003；具体来源见文末。
