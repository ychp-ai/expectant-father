# 第40周（孕晚期）

## 本周母体与胎儿状态

### 孕妇状态
- 进入预产期周，按医嘱决定待产与干预策略。
- 就医提醒：如有胎动明显减少或改变、阴道出血、阴道流液或规律宫缩，请及时联系产科医生或待产医院；情况紧急时立即就医。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 51.2 厘米，仅用于了解大致大小，不是正常值上下限。
- 已到预产期附近，但预产期只是时间估计，不能预测宝宝一定在哪一天出生。
- 宫内空间更紧凑，宝宝仍应按平时的模式活动；临近分娩不意味着胎动应该停止或明显减少。
- 若胎动较平时明显减少、消失或模式改变，应立即联系产科，不等到第二天，也不用家用胎心仪自行排除问题。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NHS-WEEK-001、MAYO-DEVELOP-003、NHS-MOVE-001；具体来源见文末。
