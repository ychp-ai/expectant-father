# 第39周（孕晚期）

## 本周母体与胎儿状态

### 孕妇状态
- 分娩临近，保持规律作息和能量补充。
- 就医提醒：如有胎动明显减少或改变、阴道出血、阴道流液或规律宫缩，请及时联系产科医生或待产医院；情况紧急时立即就医。

### 胎儿状态

- **大小参照**：NHS 本周示例头踵长（头顶到脚跟）约 50.7 厘米，仅用于了解大致大小，不是正常值上下限。
- 皮肤的保护层及皮下脂肪继续发展，为出生后的保温和适应环境做准备。
- 39～40+6 周属于国际细分中的完全足月阶段；皮肤表面仍可能保留胎脂，多少存在个体差异。

> 以上为本孕周前后的通用发育概览，存在个体差异；见[阅读说明](../README.md#如何阅读宝宝每周状态)。

本节依据：NICHD-TERM-001、NHS-WEEK-001、MAYO-DEVELOP-003；具体来源见文末。
