# 记录模板

本模块提供可复制使用的记录模板，帮助家庭把孕期和出生后的信息统一记录。

## 使用方式

- 每个模板可以复制到自己的私人记录工具中使用。
- 建议按日期持续记录，不追求一次写完整。
- 涉及检查结果和建议时，以医生、医院和官方材料为准。
- 爸爸负责维护记录结构，妈妈负责确认身体感受和个人偏好。

## 记录原则

- 记录事实，不自行下结论。
- 重要信息保留原始报告或照片。
- 每次记录都写日期。
- 异常或不确定事项及时咨询专业人员。

## 配合使用

- 从[孕期管理](../01-孕期管理/README.md)确认当前孕周和本周重点。
- 从[行动计划](../02-行动计划/README.md)选择未来阶段任务。
- 每次检查前后结合[产检指南](../03-产检指南/README.md)和产检记录模板。
- 家庭分工可参考[爸爸指南](../04-爸爸指南/README.md)。
