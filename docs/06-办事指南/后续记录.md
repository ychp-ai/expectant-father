# 后续记录

## 适用阶段

宝宝出生后持续维护，具体安排以医生、社区和当地要求为准。

## 目标

把出生后的重要时间、凭证和提醒统一记录，避免遗漏。

## 准备清单

- [ ] 保存相关记录本或凭证。
- [ ] 确认社区或机构联系方式。
- [ ] 记录首次预约或登记时间。
- [ ] 准备父母证件和宝宝资料。
- [ ] 设置后续提醒。
