# 杭州生育登记

## 是否需要办理

浙江对依法生育实行生育登记服务制度。生育登记是信息登记和公共服务衔接，不是过去需要审批后才能生育的“准生证”。

本页不预设夫妻双方的户籍、婚姻信息或常住地组合。不同家庭可能遇到不同的系统核验和线下补正要求，具体家庭分支应记录到私人位置。建议确认怀孕后在孕早期办理，方便留出信息核验和补正时间。现有官方资料没有为普通生育登记给出统一的孕周截止日，不要把网上经验中的某一孕周写成法定期限。

## 办理入口

优先使用线上入口：

1. 打开“浙里办”。
2. 搜索“生育登记”。
3. 选择“在线办理”。
4. 按页面提示填写并授权核验信息。
5. 提交后在“我的—办事记录”查询进度。
6. 办结后下载生育登记服务单并保存到私人资料夹。

应用菜单名称和页面可能调整。找不到入口时，可按事项名称搜索，不要只依赖固定层级路径。

## 办理前准备

线上系统通常会核验夫妻身份、婚姻、户籍和拟登记生育信息。办理前准备以下信息或材料，但以当次页面要求为准：

- [ ] 夫妻双方身份证信息。
- [ ] 婚姻登记信息。
- [ ] 夫妻双方户籍信息。
- [ ] 当前居住信息。
- [ ] 本次生育的胎次等基本信息。
- [ ] 系统要求补充的证明或承诺材料。

不要把身份证、户口簿或服务单照片提交到本仓库。

## 户籍不同怎样处理

夫妻户籍地不同或户籍地与常住地不同时，可先通过浙江统一线上入口按页面提示提交，不要预先假设必须回某一方户籍地办理。

如系统出现无法核验、管理地无法选择或要求线下补正：

1. 截图保存错误提示到私人位置。
2. 记录事项名称和提交时间。
3. 联系拟办理地街道或当地卫生健康部门，说明双方户籍、常住地和婚姻情况。
4. 只补交经办机构明确要求的材料。

社区建小卡按常住地辖区确认，生育登记按政务系统和卫生健康部门核验，两者不要混为同一个“管理地”问题。

## 完成标志

- 办理日期：
- 办理渠道：
- 办件编号：保存在私人位置
- 办理状态：已提交 / 补正中 / 已办结
- 生育登记服务单：已下载 / 待下载
- 后续需要提供给：医院 / 医保 / 补助申请 / 其他

办结后建议保存电子服务单，但不要为了“保险”随意把它上传给无关机构。

## 它与其他事项的关系

### 与准生证

目前办理的是生育登记服务，不是旧式准生证审批。不要搜索或套用旧版准生证材料。

### 与建小卡

生育登记是政务登记；建小卡是社区孕产妇健康管理。完成其中一个不代表另一个已经完成。

### 与产检

产检属于医疗服务。不能因为生育登记尚未办结而自行延误必要检查或急诊就医；遇到具体就医材料问题应直接询问医院。

### 与医保和生育津贴

生育登记信息可用于公共服务和后续待遇衔接，但服务单本身不等于已经完成生育医疗费用结算或生育津贴申请。分娩后仍需确认院端登记和医保办理状态。

### 与育儿补贴

育儿补贴是孩子出生后按婴幼儿户籍地办理的独立事项，生育登记办结不代表育儿补贴已经申请。符合杭州现行二孩、三孩孕产补助条件时，则应另按 2025 年新方案在孕满 24 周至婴儿出生后 180 日内申请，不能套用已废止的 2023 年旧流程。

## 常见问题

### 是否一定要到线下窗口？

杭州官方公开信息支持通过“浙里办”在线办理。只有系统要求补正、无法核验或经办部门明确通知时，再走线下渠道。

### 夫妻另一方能否代为操作？

应使用系统允许的申请人身份和授权方式，不共享账号密码。由谁登录、是否需要双方确认，以当次页面为准。

### 办结后需要打印吗？

先保存可下载的电子服务单。医院、社区或其他事项明确要求纸质件时再打印，避免把“建议备份”写成统一强制材料。
