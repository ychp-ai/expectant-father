# 建档准备

## 适用阶段

通常在孕早期开始关注，具体时间和要求以目标医院、社区和当地政策为准。

在杭州使用本资料时，应把社区小卡、医院系统产检、普通门诊档案和分娩住院登记分开。孕 13 周前到常住地所属社区卫生服务中心完成建小卡和孕早期健康管理，同时按浙大妇院当次要求建立围产保健或系统产检记录。完整名词和完成标志见[小卡、大卡与医院系统产检](./小卡大卡与医院系统产检.md)。

## 目标

提前整理建档所需资料，减少反复补材料和临时排队压力。

## 杭州社区建小卡材料

已确认社区实际办理反馈中的携带材料为：

- [ ] 前期检查报告。
- [ ] 夫妻双方身份证。
- [ ] 夫妻一方为受理地本地户籍时，携带本地户籍一方的户口本。

医保卡、居住证明、房产或租赁材料、结婚证不在这份已确认清单内，只有所属社区另行明确要求时再补充。双方都不是受理地本地户籍或属于集体户时，应在办理前单独确认。详细说明见[杭州建小卡](./杭州建小卡.md#第三步整理材料包)。

## 医院系统产检准备清单

- [ ] 确认目标医院。
- [ ] 查询是否需要预约。
- [ ] 查询围产保健手册或系统产检的时间窗口；浙大妇院公开建议孕 13 周前尽早建立。
- [ ] 准备身份证件。
- [ ] 准备医保相关材料。
- [ ] 准备既往检查报告。
- [ ] 记录末次月经日期和预产期。
- [ ] 记录医生或医院当次要求的其他材料，不把社区材料清单直接照搬为医院材料。

## 办理前确认

- 社区卫生服务中心：
- 社区建小卡状态：未咨询 / 已预约 / 已完成
- 医院所称事项的正式名称：
- 建立记录的院区、科室或入口：
- 是否需要空腹：
- 是否需要社区材料：
- 是否需要提前完成检查：
- 是否有名额、院区或时间限制：

## 完成后记录

- 社区健康档案或母子健康手册：
- 风险筛查和转诊安排：
- 医院系统产检记录建立日期：
- 产检医院、院区和后续入口：
- 后续产检安排：
- 待补材料：
- 下次办理事项：

## 爸爸负责

- 查询流程。
- 整理材料。
- 陪同办理。
- 保存回执、报告和后续安排。
