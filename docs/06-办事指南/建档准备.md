# 建档准备

## 适用阶段

通常在孕早期开始关注，具体时间和要求以目标医院、社区和当地政策为准。

## 目标

提前整理建档所需资料，减少反复补材料和临时排队压力。

## 准备清单

- [ ] 确认目标医院。
- [ ] 查询是否需要预约。
- [ ] 查询建档时间窗口。
- [ ] 准备身份证件。
- [ ] 准备医保相关材料。
- [ ] 准备既往检查报告。
- [ ] 记录末次月经日期和预产期。
- [ ] 记录医生或医院要求的其他材料。

## 办理前确认

- 建档地点：
- 是否需要空腹：
- 是否需要社区材料：
- 是否需要提前完成检查：
- 是否有名额或时间限制：

## 完成后记录

- 建档日期：
- 建档医院：
- 后续产检安排：
- 待补材料：
- 下次办理事项：

## 爸爸负责

- 查询流程。
- 整理材料。
- 陪同办理。
- 保存回执、报告和后续安排。
