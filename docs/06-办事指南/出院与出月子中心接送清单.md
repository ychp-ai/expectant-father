# 出院与出月子中心接送清单

用于提前安排医院出院后回家或前往月子中心，以及离开月子中心回家的接送。默认是同城乘车，适用于自家车、网约车或机构接送车；长途或母婴有特殊健康情况时，先向医护确认是否适合出行及途中安排。

**宝宝全程使用适合体型的后向式安全座椅，妈妈和其他成人各自系好安全带。**出院先完成医疗交接，离开月子中心先完成家人接手照护的交接。

> 本内容用于家庭准备与交接参考，不能替代医生诊疗意见。如有不适或异常，请及时联系医护或前往医院。

## 两次接送都要准备

### 必须完成：车辆与约束装置

- [ ] 选适合宝宝当前身高、体重且从出生适用的后向式座椅或车载安全提篮，确认与车辆相容；普通手提篮、推车睡篮不能直接替代。
- [ ] 提前按汽车和座椅说明安装在后排，试好固定方式、倾斜角度和约束带；不放在有启用正面安全气囊的副驾驶座。
- [ ] 照护者练习放入宝宝、扣紧和调节约束带；车程短也不能抱着替代。
- [ ] 宝宝穿合身衣物，不裹厚包被再扣约束带；需要保暖时把薄毯盖在扣好的带子外面，脸部露出。
- [ ] 不自行加装头枕、软垫或约束带附件，只使用原配或制造商明确允许用于该型号的配件。
- [ ] 每名成人有自己的座位和安全带，不共用安全带，不抱着宝宝一起扣成人安全带。

依据 AAP-CARSEAT-001；具体安装以汽车和座椅说明为准，不照搬海外产品认证或交通法规。

### 建议准备：分工与随身物品

- [ ] 司机之外建议另有一名健康、清醒的成人坐后排照看宝宝；爸爸开车时，另安排照护者。
- [ ] 确认接车时间、实际院区或机构出口、停车点及上下车路线，留够座椅、成人和行李空间。
- [ ] 司机充分休息，路线尽量直接，避免顺路购物、聚餐或长时间拍照。
- [ ] 行李先装好再接母婴，减少门口等待；妈妈不搬行李、不提装着宝宝的提篮。
- [ ] 随身包放尿裤、清洁用品、换洗衣物、按天气准备的薄毯、妈妈饮水及实际需要的喂养用品。
- [ ] 按天气调节车内温度，避免过热和包裹过厚，不为防风而遮住宝宝脸部。

后排照护、随身物品和避免车内过热参考 AAP-CARTRAVEL-001；人员分工、接车顺序和路线为家庭安排建议。

### 网约车与机构车辆：接车前确认

| 核对项 | 问清什么 |
|---|---|
| 座椅 | 是否提供从出生适用的后向式座椅；自带时车辆是否支持正确安装 |
| 安装 | 谁负责安装和检查，是否预留安装时间；换车后重新核对 |
| 人员 | 谁照看宝宝、谁帮助妈妈上下车；所有成人是否都有安全带 |
| 接车 | 接车点、等待安排、行李空间与搬运负责人 |

有专车或护理人员不代表已满足乘车条件；不能正确安装合适座椅时，先调整车辆或接送方案。

## 医院出院：必须完成医疗交接

- [ ] 向病区确认妈妈和宝宝各自的出院安排，不按预订入住日或预计住院天数推算可以出院。
- [ ] 问清各自用药、复诊、待出结果和需立即求助的情形，由家人复述核对。
- [ ] 带齐医院交付的出院记录、药品或处方、筛查与接种资料及复诊安排；出生医学证明未领取时确认后续方式。
- [ ] 直接去月子中心时，确认入住时间、接收人员，把医院要求交给实际照护者；医院要求的复诊或治疗仍按医嘱完成。
- [ ] 妈妈行走或上下车不舒服时向病区询问是否需要轮椅等协助；剖宫产后由他人驾驶和搬运，恢复开车按身体恢复及医生意见判断，不以“满月”为自动恢复标志（NHS-CAESAREAN-001）。
- [ ] 早产、低出生体重或有呼吸等问题的宝宝，问儿科医生普通座椅是否适用、是否需要乘车耐受评估或特殊转运，不自行用软垫改装（AAP-CARSEAT-001）。

结算、物品归还和文件交接沿用[浙大妇院出院交接](./浙大妇院住院须知与物品清单.md#出院前必须完成交接)；具体院区、科室、时间和报到地点按当次通知确认。月子中心入住和接车要求为机构核对项，不外推为统一流程。

## 离开月子中心：建议提前一天完成接手交接

- [ ] **宝宝**：当前喂养方式、最近一次喂养和换尿布时间、近期记录、尚待落实的医生要求、复诊和接种安排。
- [ ] **妈妈**：尚未完成的医嘱、正在使用的处方药、产后复查和医生交代的关注事项；离开中心不等于医学复查已完成。
- [ ] **家人操作**：回家后的照护者练习抱放宝宝、换尿布、按现有指导喂养及扣安全座椅，不明白的步骤当场核对。
- [ ] **家庭准备**：独立、坚实平坦的婴儿睡眠空间、尿裤衣物；需要瓶喂时落实奶具清洁、消毒和干燥条件，见[宝宝出生后日常用品](../05-物资准备/宝宝出生后日常用品.md)。
- [ ] **资料物品**：清点证件、医疗资料、个人物品和费用明细，确认借用物品归还及遗留物品处理。
- [ ] **符合条件时**：带走储存母乳前核对冷链运输、途中时长和到家存放安排，按适用喂养与储存指导执行。

此交接清单为家庭建议，不代表机构统一服务标准；具体机构和家庭交接结果只记录在受控私人位置。

## 路上与到达后：必须遵守

- [ ] 妈妈以能正确系安全带的姿势乘坐，不横躺在后排；其他成人也全程系好安全带。
- [ ] 宝宝全程扣好约束带，照护者观察脸部是否露出、头部有无过度前垂及呼吸异常。
- [ ] 喂奶、换尿布、调整姿势或抱起安抚前，先在安全地点停车；继续行驶前重新检查约束带。
- [ ] 行程较长时预设休息点，结合母婴状态和医护建议调整，不把网上固定时长当作所有新生儿均能连续乘坐的保证。
- [ ] 到达后及时移到合适的平坦睡眠空间并仰卧安置，不把车载提篮当日常睡床，见[睡眠环境准备](../05-物资准备/宝宝出生后日常用品.md#睡眠回家前必须具备)。
- [ ] 不把宝宝单独留在车内，即使只是结账、搬行李或停车。

途中观察、停车喂养和到达后转移依据 AAP-CARTRAVEL-001；睡眠环境和奶具卫生分别依据 NICHD-SLEEP-001、CDC-FEEDHYGIENE-001。

## 出现异常：先求助

出发前出现以下情况，先联系医护或急救；途中出现时安全停车，立即求助：

- **妈妈**：明显大量出血（例如一小时浸透一片或更多卫生巾）、胸痛、呼吸困难、晕厥，或持续加重的剧烈头痛伴视物异常等（CDC-MATERNALWARNING-001）。
- **宝宝**：呼吸困难、嘴唇或舌头发青、难以唤醒等（NHS-BABYWARNING-001）。

严重情况拨打 **120**，说明母婴状态和当前位置，按急救人员指导行动，不继续赶往月子中心或家里等待观察。上列情形不是完整症状清单，也不用于家庭诊断。
