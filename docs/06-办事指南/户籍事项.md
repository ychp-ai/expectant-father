# 户籍事项

## 适用阶段

宝宝出生后根据家庭安排和当地要求办理，具体流程以当地官方渠道为准。

## 目标

提前整理户籍相关材料和办理路径，减少来回补材料。

## 准备清单

- [ ] 查询办理地点或线上入口。
- [ ] 确认办理时间要求。
- [ ] 准备出生相关资料。
- [ ] 准备父母身份证件。
- [ ] 准备家庭户口资料。
- [ ] 确认是否需要双方到场。
