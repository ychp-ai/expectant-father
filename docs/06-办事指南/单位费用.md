# 单位与费用事项

## 适用阶段

建议在孕中期或孕晚期前提前了解，避免临近生产时再集中处理。

## 目标

整理单位请假、福利、费用报销和保险相关信息，明确需要准备的材料和时间节点。

## 信息清单

- [ ] 单位请假流程。
- [ ] 产检请假规则。
- [ ] 产假或陪产假规则。
- [ ] 费用报销要求。
- [ ] 医保或商业保险材料要求。
- [ ] 发票、清单和报告保存方式。
- [ ] 联系人和咨询渠道。

## 需要确认

- 单位联系人：
- 需要提前提交的材料：
- 费用报销渠道：
- 报销截止时间：
- 是否需要纸质原件：
- 是否需要医院盖章或证明：

## 材料归档

- 产检发票：
- 检查报告：
- 医院清单：
- 请假记录：
- 单位说明：
- 保险材料：

## 爸爸负责

- 建立费用文件夹。
- 保存票据和电子材料。
- 记录咨询结果。
- 提醒提交时间。
