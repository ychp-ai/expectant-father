# 单位与费用事项

## 使用边界

本页只作为夫妻双方单位和费用事项的通用核对模板。杭州职工劳动权益见[杭州职工生育权益](./杭州职工生育权益.md)，医保待遇见[杭州职工医保与生育保险](./杭州职工医保与生育保险.md)。生育医疗费用、生育津贴和单位工资必须分开记录。

## 女方单位

- [ ] 产检时间申请和紧急补录流程。
- [ ] 孕期禁忌劳动、减轻劳动量、岗位调整的申请方式。
- [ ] 妊娠反应严重或孕 7 个月以上时的休息、加班和夜班保护。
- [ ] 一孩 158 天、二孩或三孩 188 天产假及难产（包括剖宫产）、多胞胎增加天数。
- [ ] 产假期间工资、奖金、社保、公积金与津贴差额处理。
- [ ] 产后复工的哺乳时间和排班保护。
- [ ] 单位额外慰问金、商业保险或托育福利是否存在。
- [ ] 单位是否符合女职工产假期间社会保险补贴条件；该款由单位申请和收取。

## 男方单位

- [ ] 15 天护理假的申请入口、证明和分次使用规则。
- [ ] 系统是否排除法定节假日、休息日和职业假。
- [ ] 护理假期间工资、奖金和其他福利是否照发。
- [ ] 单位额外生育慰问金、商业保险或其他家庭福利是否存在。

## 双方共同核对

- [ ] 子女三周岁内每人每周年 10 天育儿假的申请入口。
- [ ] 育儿假的周年起止日、分次使用和不可结转规则。
- [ ] 杭州职工医保和生育保险连续缴费状态。
- [ ] 产检和分娩医疗费用结算方式。
- [ ] 生育津贴申请、本人收款账户和单位工资衔接。
- [ ] 医保或商业保险材料、票据和申请期限。
- [ ] 符合多子女家庭条件时的公积金贷款或租房提取优惠。
- [ ] 夫妻任何一方符合失业人员条件时的生育补助金。

## 费用归档

爸爸可以协助建立私人资料夹，分开保存：

- 医保结算票据和费用清单。
- 商业保险要求的发票、诊断和申请记录。
- 双方单位的请假、考勤和制度页面。
- 生育津贴申请、到账和工资衔接记录。
- 公积金或单位福利的申请材料。

单位名称、人事联系人、工资、账户、票据、报告、申请编号和完成状态只记录在个人资料仓库的当前记录页或受控家庭资料中，不填入本页。
