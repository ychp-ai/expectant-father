# 办事指南

本模块整理孕期到宝宝出生后常见事务的准备清单和记录模板。

具体流程以当地官方渠道、医院、社区和单位要求为准。

## 使用方式

- 先查看事项导航。
- 每个事项记录材料、渠道、状态和下一步。
- 所有资料和回执统一归档。
- 爸爸负责维护清单和提醒。

## 记录位置

事项负责人、家庭分支、办理状态、回执和下一步只填写到个人资料仓库的当前记录页或受控的家庭私人资料。本模块只保留通用规则和空白模板。
