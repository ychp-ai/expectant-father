# 办事指南

本模块整理孕期到宝宝出生后常见事务的准备清单和记录模板。

不同城市、医院、社区和单位要求差异较大，本模块只用于家庭准备和信息记录，具体流程以当地官方渠道、医院、社区和单位要求为准。

## 使用方式

- 先查看事项导航，确认当前阶段需要关注的事项。
- 每个事项都记录：办理对象、时间、材料、渠道、状态和下一步。
- 所有证件、报告和回执统一归档。
- 爸爸负责维护清单、预约提醒和材料备份。
