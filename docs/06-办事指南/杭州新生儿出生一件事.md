# 杭州新生儿出生一件事

## 适用范围

本页用于孩子在杭州出生后办理基础证件和登记，覆盖出生医学证明、预防接种证、国内出生户口登记、新生儿基本医保及可选社保卡等联办衔接，不扩展长期育儿事项。

“出生一件事”是把多个部门事项放到一个入口协同办理，不代表所有家庭、所有事项都自动适用，也不代表提交一次后每个事项同时办结。开始前应在浙江政务服务网或“浙里办”搜索“出生一件事”，查看当次适用条件、可选事项和材料。

## 孕晚期先准备

- [ ] 确认父母证件上的姓名、证件号码和婚姻信息一致，发现差异先咨询责任部门。
- [ ] 讨论宝宝姓名和拟落户方向；不要仅为抢时间提交尚未确认的信息。
- [ ] 向计划分娩医院确认出生医学证明首次签发方式、办理地点、所需原件及是否支持线上联办。
- [ ] 询问预防接种证由医院直接建立、联办还是需要出生后到居住地接种单位办理。
- [ ] 根据拟落户地确认户籍登记条件，不根据家庭经验推断孩子一定能随某一方落户。
- [ ] 确认新生儿拟参保地、缴费方式，以及医保码或社保卡是否需要另行激活。
- [ ] 在私人资料中指定一名经办人和一名复核人，不在通用文档填写证件信息。

## 出生后办理顺序

### 1. 先核对出生信息

核对医院记录中的孩子出生日期、时间、性别、母亲信息和拟用姓名。发现不一致时先联系分娩机构，不要带着错误信息继续提交户籍或医保事项。

### 2. 打开当次联办入口

通过浙江政务服务网或“浙里办”搜索“出生一件事”，逐项查看：

- 当前家庭是否符合线上联办条件。
- 可勾选哪些事项，哪些必须另行办理。
- 申请人应由父亲、母亲还是其他符合条件的监护人担任。
- 是否需要上传或调取出生医学证明、父母身份、婚姻、户籍等信息。
- 原件核验、领取或邮寄方式，以及每个事项的承诺时限。

如果页面条件与家庭情况不一致，使用对应部门的单事项渠道，不为进入联办流程而选择错误分支。

### 3. 分项提交并逐项跟踪

常见联办事项可能包括：

- 出生医学证明首次签发。
- 预防接种证办理或接种档案建立。
- 国内出生户口登记。
- 新生儿城乡居民基本医保参保登记。
- 社会保障卡申领等可选事项。

以当次页面实际展示为准。提交后分别记录每个事项的受理、补正、办结或退回状态；某一项办结不代表其余事项已经完成。

### 4. 完成医保后续动作

参保登记完成后，继续确认是否已缴费、待遇起始时间、医保码激活和就医结算方式。杭州现行医保办法规定，符合参保条件的新生儿自出生之日起 3 个月内办理参保缴费，可从出生之日起享受该结算年度剩余月份待遇，但不得早于符合参保条件的时间。

这条规则强调的是“参保并缴费”，仅看到参保登记受理不等于已经完成。超过窗口可能影响待遇起始或产生等待期，应尽量提前办理，并以杭州医保当次审核为准。

### 5. 单独处理未纳入联办的事项

以下事项不要视为“出生一件事”提交后自动办结：

- 生育津贴状态查询及单位工资衔接。
- 杭州孕产补助或三孩补助的申请和状态。
- 育儿补贴首次申请及后续年度续领。
- 3 岁以下婴幼儿照护个人所得税专项附加扣除。
- 夫妻双方育儿假、女方哺乳期劳动保护和多子女家庭公积金优惠。

孩子具备出生医学证明和户籍等所需资料后，应按各自入口、条件和时限分别办理。

## 完成标志

- [ ] 出生医学证明已按医院要求领取或确认领取方式。
- [ ] 预防接种证或电子接种档案已建立，出生医院首剂疫苗记录和下次接种安排已保存。
- [ ] 户籍登记已有明确结果；如退回，已记录补正原因和责任部门。
- [ ] 新生儿医保参保登记与缴费状态均已确认。
- [ ] 医保码或社保卡等后续激活动作已完成或有明确提醒。
- [ ] 每个事项的结果、回执位置和下一步只记录在私人资料中。
- [ ] 国家育儿补贴已作为独立事项加入出生后清单。
- [ ] 杭州孕产补助、三孩补助和婴幼儿照护个税扣除已分别核对适用性。
- [ ] 双方育儿假和女方复工保护已加入家庭提醒；符合条件时已加入公积金复核提醒。

## 资料归档

出生后只归档基础文件和必要登记结果，不在本项目扩展长期照护记录：

- [ ] 医院提供的出生、住院和出院文件已保存。
- [ ] 出生医学证明、户籍、医保和社保卡办理结果已分别归档。
- [ ] 医疗费用票据和清单已保存到私人资料夹。
- [ ] 每个事项的回执、补正要求、负责人和下一步已记录。
- [ ] 需要持续保留的原件与电子备份位置已由家庭成员确认。

具体出生信息、证件资料和办理状态可复制[出生信息记录模板](../08-记录模板/出生信息记录.md)到私人位置填写。

## 无法联办时

- 出生医学证明问题：联系分娩机构的签发窗口。
- 户籍登记问题：联系拟落户地公安户籍窗口。
- 医保参保、缴费或待遇问题：联系杭州医保渠道或拟参保地经办机构。
- 页面无法匹配家庭情况：保存错误提示到私人位置，记录发生时间和咨询答复，改走责任部门确认的单事项渠道。

医疗急需不能因证件或联办流程尚未完成而延误；先按医疗机构指引就医，再处理登记和结算衔接。

## 隐私与归档

- 出生医学证明、户口簿、身份证、银行卡、回执编号、二维码和页面截图只保存在私人资料夹。
- 通用仓库只维护流程和空白清单，不记录宝宝姓名、证件号码、详细出生信息或家庭户籍分支。
- 邮寄证件时在私人日历记录物流，不把地址或单号写入 Git。
