# 杭州建小卡

## 先分清两件事

“建小卡”通常指在居住地所属社区卫生服务中心建立孕产妇健康管理记录；它不等同于在浙江大学医学院附属妇产科医院完成首次产检或院内建档。

两边的记录可能会互相使用，但办理地点、材料和检查安排并不完全相同。不要只完成医院就诊后就默认已经建好小卡。

## 建议什么时候开始

确认怀孕后即可联系居住地所属社区卫生服务中心。按照现行基本公共卫生服务规范，应在孕 13 周前建立母子健康手册或孕产妇健康档案，并完成第一次孕早期健康管理；实际受理条件和预约时间以所属社区通知为准。

如早孕复查尚未完成，可以先电话核实社区要求；是否需要等复查结果、B 超报告或医生确认孕周后再办理，以所属社区答复为准。

## 第一步：确认所属社区

先整理当前实际居住地所属区、街道或乡镇、社区和详细地址，用于向社区确认受理范围。详细地址、机构电话和咨询结果只填写到个人资料仓库的当前记录页，不要直接写入本页。

如果不确定归属，可先联系街道、社区或附近社区卫生服务中心，报实际居住地址确认。户籍地与常住地不一致时，要特别询问按哪一方受理。

基层孕产妇健康管理面向辖区常住孕产妇，表单可能区分户籍与非户籍；因此应先按杭州实际居住地址确认所属中心。社区对连续居住时间或居住材料有具体要求时，再按其答复补充。

## 第二步：办理前电话核实

建议逐项询问并记录答复：

- [ ] 本地址是否属于该中心的孕产妇健康管理范围。
- [ ] 具体办理科室、地址、工作时间和联系电话。
- [ ] 是否需要预约，线上还是电话预约。
- [ ] 夫妻双方身份证、前期检查报告以及本地户籍一方的户口本分别需要原件、复印件还是电子材料。
- [ ] 双方都不是受理地本地户籍或属于集体户时，材料怎样调整。
- [ ] 是否会安排抽血、尿检、血压等项目，是否需要空腹或留晨尿。
- [ ] 孕妇是否必须本人到场，家属能否代办部分手续。
- [ ] 建立的是纸质手册、电子档案，还是两者都有。
- [ ] 完成后哪些资料需要带去浙大妇院产检。

> 已知社区实际办理反馈中，当天要求空腹到场。若所属社区已经给出相同通知，应按通知执行；尚未确认时，不要据此推断杭州所有社区都要求空腹。电话确认时应一并问清从几点开始禁食、能否饮水、晨间药物怎样处理以及是否需要留晨尿，不自行停用处方药。

## 第三步：整理材料包

已确认社区实际办理反馈中，建小卡携带材料只有下面三类。杭州各区、街道和社区可能存在差异，出发前仍应确认材料形式；双方都不是受理地本地户籍或属于集体户时，应单独询问。

### 必带材料

- [ ] 建小卡前已经取得的检查报告，包括已有的确认怀孕、B 超、抽血、尿检等报告；只整理现有报告，不为凑材料自行补做或重复检查。
- [ ] 夫妻双方身份证。
- [ ] 夫妻一方为受理地本地户籍时，携带本地户籍一方的户口本；另一方的户口本不在这份已确认清单内。

医保卡、社保卡、居住证明、房产或租赁材料、结婚证不在这份已确认材料清单内；只有所属社区另行明确要求时再补充，不默认携带。

### 现场可能需要说明的信息

- [ ] 末次月经第一天。
- [ ] 医生确认的孕周和预产期；尚未确认可先留空。
- [ ] 既往孕产史、疾病史、手术史、过敏史。
- [ ] 当前药物和营养补充剂清单。

这些属于现场健康信息采集，不是上述三类携带材料。具体病史、用药和孕周记录只保存在私人资料中。

### 便于现场处理

- [ ] 已按所属社区通知完成空腹等检查前准备。
- [ ] 手机和充电设备。
- [ ] 黑色签字笔。
- [ ] 所有报告的电子备份。
- [ ] 如需空腹，准备检查结束后可及时食用的水和简便食物。

## 第四步：现场办理流程

各社区顺序可能不同，一般可按以下思路准备：

1. 到指定科室报到，核验身份、居住地和受理范围。
2. 登记末次月经、孕周、预产期、联系方式等孕情信息。
3. 填写既往病史、孕产史、家族史、用药史和生活情况。
4. 接受社区安排的基础评估、健康教育或检查。
5. 工作人员进行妊娠风险初筛；筛查异常时，按要求到上级医疗机构评估或转诊。
6. 建立纸质或电子孕产妇健康管理记录。
7. 核对下一次社区随访、医院产检和待补材料。

如现场安排检查，空腹、饮水、晨间药物和留尿要求以社区提前告知为准；没有收到明确要求时不要自行猜测。

## 第五步：办完后立即记录

在个人资料仓库的当前记录页中记录办理日期、机构和科室、手册或电子档案状态、下次随访、待补材料及需要带去医院的资料。电话、详细地址、孕周、预产期、风险评估、转诊信息和检查结果也只保存在私人位置。

将回执、手册和检查报告保存到受控的私人资料夹，不要把身份证号、住址、电话、风险评估或报告照片提交到公开代码仓库。

建小卡完成后仍应按社区通知参加随访，并按浙大妇院医嘱完成医院产检。社区健康管理不能替代医院对个人病情、检查结果或高风险妊娠的诊疗。

## 建卡后：核对社区免费服务

现行国家基本公共服务标准和基本公共卫生服务规范共同明确，孕产妇可免费接受孕早期 1 次、孕中期 2 次、孕晚期 2 次健康管理；首次孕早期健康管理包括建立母子健康手册或相应健康记录。浙江和杭州已经完成地方标准迭代，具体承接仍由所属基层医疗卫生机构落实。已确认的所属社区实际办理反馈还包括：建小卡后可以领取或登记一次免费中期血清学产前筛查服务。

这批免费服务有明确的办理地点边界：按照当前已确认的社区口径，只能在所属社区卫生院（社区卫生服务中心）办理，不能把券或免费次数带到浙大妇院及其他医院抵扣。社区是否现场采血、样本送往哪家有资质的产前筛查机构以及报告由谁出具，应由社区说明。

办完小卡后逐项确认：

- [ ] 免费中期血清学产前筛查的适用条件、有效孕周、预约方式和是否需要领纸质或电子券。
- [ ] 是否必须回本社区采血或检查，具体科室、日期和准备要求。
- [ ] 5 次免费孕期健康管理分别安排在哪些孕周，是否需要每次单独预约。
- [ ] 每次健康管理具体包含哪些项目，以及社区异常结果如何转至产检医院。
- [ ] 报告领取方式、结果同步方式及需要带回浙大妇院的资料。

“5 次免费健康管理”不能简称为“5 次免费胎心监护”：第 2～5 次社区随访记录通常包含胎心率等基础产科检查，但这不等同于医院孕晚期的无应激试验（NST）。医院是否安排胎心监护以及频次，仍由产检医生决定。

## 与早孕复查衔接

早孕复查时可以请医生明确以下事项，并同步更新社区记录：

- [ ] 本次 B 超确认的孕周和预产期。
- [ ] 当前是否适合办理或补全小卡信息。
- [ ] NT 检查的合适日期、预约方式和就诊院区。
- [ ] NT 当天是否有特殊准备，以及需要携带哪些报告。
- [ ] 社区检查与医院检查是否有重复，哪些结果可以互认或供医生参考。

NT 通常安排在孕 11～13+6 周，但个人预约日期应由医生结合孕周和医院安排确认。

## 爸爸可以负责

- 根据实际住址确认所属社区卫生服务中心。
- 电话核实并逐项记录办理要求，不凭记忆转述。
- 按“原件、复印件、报告、待咨询问题”分类整理材料。
- 陪同办理，保管回执并记录下一次随访时间。
- 将早孕复查、小卡和 NT 待办放进同一个家庭日历。
