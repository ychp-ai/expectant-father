# 出生资料

## 适用阶段

宝宝出生后尽快整理，具体资料名称、办理窗口和时间要求以医院和当地规定为准。

## 目标

把出生相关资料集中归档，为后续办理证明、医保、户籍和其他事项做准备。

## 资料清单

- [ ] 医院提供的出生相关文件。
- [ ] 父母身份证件。
- [ ] 户口本或家庭相关资料。
- [ ] 住院和出院材料。
- [ ] 费用票据和清单。
- [ ] 宝宝基础信息记录。

- 是否需要提前预约：

- 是否有办理时间限制：
- 是否可线上办理：

## 爸爸负责

- 统一保存出生相关资料。
- 复印或扫描重要文件。
- 记录后续办理顺序。
- 提醒材料截止时间。
