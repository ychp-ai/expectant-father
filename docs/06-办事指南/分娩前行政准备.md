# 分娩前行政准备

## 什么时候开始

建议孕 28 周后开始整理，孕 33～36 周向浙大妇院确认实际分娩院区、入院流程和材料，孕 37 周前完成家庭演练。医生提示早产、高风险或需要提前住院时，应提前处理。

浙大妇院现有湖滨、钱江和余杭院区。官网公开地址不能证明某位孕妇一定在哪个院区产检、急诊或分娩，所有安排以当次预约、医生和医院通知为准。

## 第一步：确认分娩和急诊路径

在孕晚期产检时逐项询问：

- [ ] 计划分娩院区和具体地址。
- [ ] 常规住院从哪里报到，是否需要医生开具住院单。
- [ ] 夜间、周末或突发情况去哪个产科急诊入口。
- [ ] 临产、破水、出血或胎动异常时先联系谁。
- [ ] 是否有院区调配或床位安排，怎样接收变更通知。
- [ ] 陪同人员和车辆在哪里等候，停车或公共交通替代方案。
- [ ] 医生认为应直接急诊而非等待预约的情形。

把院区、入口和联系电话保存到夫妻手机及家庭私人记录中。医院总机可辅助问路，但紧急医疗判断应遵循医生和急诊指引。

## 第二步：确认医院当次材料

以下是建议整理的基础类别，不是浙大妇院永久固定的入院清单：

### 身份与医保

- [ ] 孕妇本人身份证件。
- [ ] 医保码或社会保障卡。
- [ ] 陪同家属身份证件，仅在医院明确要求时携带。
- [ ] 生育登记服务单电子备份。

### 孕期健康资料

- [ ] 母子健康手册或社区孕产妇健康记录。
- [ ] 产检病历和医生要求携带的报告。
- [ ] 血型、过敏史、疾病史和当前用药信息。
- [ ] 高风险评估、转诊或专科会诊资料。
- [ ] 医院预约、住院单或床位通知。

### 费用和联系信息

- [ ] 可正常使用的支付方式。
- [ ] 医院医保结算疑问清单。
- [ ] 本人和紧急联系人电话。
- [ ] 单位人事或医保经办人联系方式，保存在私人位置。

办理前再次向医院确认是否需要原件、复印件、纸质报告或额外材料。

## 第三步：医保与单位复核

- [ ] 生育时预计处于杭州职工医保待遇期，申领时预计在杭州市连续缴费满 6 个月。
- [ ] 医保码或社会保障卡可以使用。
- [ ] 分娩医院和院区的结算方式已确认。
- [ ] 生育服务包备案和结算明细已核对，包外、超标准或额外服务的费用方式已问清。
- [ ] 院端生育信息登记方式已了解。
- [ ] 本人生育津贴收款账户可正常使用。
- [ ] 女方一孩 158 天、二孩或三孩 188 天产假及增加天数已与单位确认。
- [ ] 产假期间工资、津贴、奖金、社保和公积金衔接已确认。
- [ ] 男方 15 天护理假的申请、分次使用和工资福利已确认。
- [ ] 双方子女三周岁内每周年各 10 天育儿假的入口已确认。

如分娩前离职、换单位、断缴或改为异地分娩，应立即重新向医保和单位核实，原结论不再直接适用。

生育服务包的“零自付”只适用于清单和支付标准内项目。省外异地分娩通常需要先垫付后申请，不能把省内直接结算方式照搬到跨省场景。

## 第四步：出生信息预核对

孕期只做基本信息准备，不在本项目扩展完整的出生后办证流程：

- [ ] 核对父母身份证件上的姓名、证件号码和民族等信息。
- [ ] 确认证件是否在有效期内，原件放在哪里。
- [ ] 提前讨论新生儿姓名，准备备选写法。
- [ ] 了解医院签发出生医学证明时由谁核对信息。
- [ ] 明确任何信息不一致时先咨询医院，不自行涂改材料。

真实证件信息和新生儿姓名不提交到公开仓库。

## 第五步：建立两个资料包

### 随身纸质包

只放医院明确要求的原件、手册、报告和少量复印件。每次孕晚期复诊后检查是否有新增材料。

### 私人电子包

保存预约、报告、费用凭证、单位审批和医保状态截图。应设置设备锁或访问权限，不使用公开链接分享。

## 家庭演练

孕 37 周前至少完成一次：

1. 丈夫在不看聊天记录的情况下说出计划院区和急诊入口。
2. 从家里规划主路线和备用路线。
3. 检查证件包、手机、充电和支付方式。
4. 模拟夜间出发时由谁拿资料、谁联系医院、谁处理车辆。
5. 复述医生要求立即就医的警示信号。

演练不是为了自行判断能否在家等待；出现异常或不确定时，应及时联系医疗机构。
