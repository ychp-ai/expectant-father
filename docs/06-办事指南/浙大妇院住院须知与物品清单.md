# 浙大妇院住院须知与物品清单

适用于在浙江大学医学院附属妇产科医院（省妇保、浙大妇院）准备分娩住院的家庭，覆盖入院、住院配合和出院交接。湖滨、钱江、余杭院区及不同病区的安排可能不同，实际院区、科室、时间和报到地点必须按当次通知确认。

先做三件事：确认实际住院病区；向病区索取当次物品清单；按[待产包](../05-物资准备/待产包.md)的四袋分类准备。该页提供约 24 小时起步量和约 3 天备量，属于家庭预算，不是医院指定数量或预计住院天数。

## 先分清哪些已经确认

| 内容 | 本次核对结论 |
|---|---|
| 住院预约及人工手续地点 | 官网有三个院区的说明，见下表；预约、办理手续与到病区报到是不同步骤 |
| 医院提供的房间设备 | 官网明确介绍了**余杭院区国际化病房套房**的部分设备，不能套用到普通病房 |
| 普通产科病房的生活用品与母婴耗材 | 本次未查到现行、跨院区统一供应清单；不能据此认定“全都提供”或“全都不提供” |
| 物品收费、领取数量和带走规则 | 未获得统一公开说明，须向实际病区确认；“配备”“可借用”“有售”和“免费发放”要分开问 |

不采用第三方旧攻略中的热水瓶供应、固定探视时段、疫情期间陪护规则等作为现行要求，也不把其他医院的待产包要求写成省妇保规定。

## 入院前必须完成：确认流程和资料

医院官网《住院服务》公布的地点如下（来源：WHZJU-INPATIENT-001）：

| 院区 | 住院预约地点 | 人工办理住院手续地点 |
|---|---|---|
| 湖滨 | 1 号楼 2 楼入院准备中心 | 2 号楼 1 楼综合服务中心 |
| 钱江 | 2 号楼 1 楼大厅综合服务中心 | 2 号楼 1 楼综合服务中心 |
| 余杭 | 1 楼 B 区综合服务中心 | 1 楼 B 区综合服务中心 |

- [ ] 预约时备好就诊病历、住院申请单，按申请单提示填写住院信息，到相应地点取号候叫。
- [ ] 确认自己是否属于预住院：官网说明非预住院患者可手机端自助预约或人工办理；预住院须先到综合服务中心人工办理，再安排院前检查。
- [ ] 官网允许选择任一院区办理住院预约；这不等于可自行决定实际收治院区、病区或床位。另行确认到哪里住院、何时到场及如何接收通知。
- [ ] 核对当次身份、医保及陪护材料要求。家庭基础资料袋可先放产妇身份证、可用的医保结算凭证、孕期记录及重要报告、入院材料、支付工具和当前用药清单。
- [ ] 另存夜间或紧急就诊入口。上表不是产科急诊路线；需要急诊时不等预约、不为凑齐物品延误就医。

身份、医保和家庭资料的准备类别见[分娩前行政准备](./分娩前行政准备.md)，不能把上面的预约材料理解成全部入院材料。

## 携带物品：先备基础用品，指定耗材先问病区

下表为家庭打包建议，通用品类沿用 CN-BIRTHBAG-001、NHS-BIRTHBAG-001；**不是浙大妇院官方必带清单**。医院明确供应的用品可按领取条件减量；具体数量统一查看[待产包](../05-物资准备/待产包.md)，避免重复维护两套数字。

| 分类 | 建议自备 | 减量或装箱前的确认项 |
|---|---|---|
| 资料袋 | 证件、医保凭证、孕期资料、住院材料、用药清单、手机及支付工具 | 原件、复印件和电子资料是否均可用；陪护是否要证件 |
| 妈妈卫生用品 | 内裤、大号卫生巾、牙刷牙膏、毛巾、梳子、抽纸厕纸、脏衣袋 | 是否有收费生活包，是否自愿购买，包含什么 |
| 妈妈衣物与日用品 | 防滑拖鞋、水杯、换洗衣物及出院衣物 | 病号服是否发放和更换；订餐是否附餐具；勿默认有洗漱用品 |
| 宝宝用品 | 合适尺码纸尿裤、清洁用品、衣物，另留出院衣物；按天气备外出包被 | 病房和产房分别是否提供宝宝衣物、包被；自带物是否允许、规格是什么 |
| 陪护用品 | 自己的换洗和洗漱用品、水杯、手机充电器、资料收纳袋 | 夜间能否留宿；陪护床、被褥是否可借、是否收费；补送物品交接地点 |
| 产房交接袋 | 病区确认后，把指定物品单独装袋并标清类别 | 护理垫、刀纸、尿裤、婴儿衣物及包被的种类、尺寸、数量，不按网帖购买指定套装 |
| 医护评估后准备 | 吸奶器、储奶及奶具、配方奶、腹带、会阴或伤口护理用品 | 是否需要、能否自带、如何清洁及使用；不自行加用药品或护理产品 |

建议把备用消耗品留在家中并约定补送人。婴儿乘车座椅提前装在车内；整套洗澡设备、大型电器不默认搬入病房。

## 医院提供什么：已公开配置与待确认物品

### 已公开：仅限余杭院区国际化病房套房

医院官网介绍套房配备电视、冰箱、微波炉、电热水壶、电吹风和智能马桶，并有客厅与卧室分区；病区另设会客厅。该介绍还说明家属可在房间内陪伴待产、分娩及产后恢复（来源：WHZJU-ROOM-001）。

这些是特定病房的设施和服务介绍，不代表全院普通病房配置，也不代表设备可带走、房型有空位或相关服务免费。入住资格、适用分娩情形、实际房间配置、陪护限制及费用仍须当次确认。医院房内配有电器，也不等于允许自带同类电器。

### 普通病房及其他房型：逐项向病区确认

以下项目本次均未确认统一供应安排，打包前按实际院区、病区逐项询问：

| 物品或服务 | 需要问清什么 |
|---|---|
| 产妇病号服、床上被褥 | 是否由病区提供；更换方式；是否还需自带衣物 |
| 宝宝住院衣物、包被 | 产房与病房是否分别提供；是否仅住院期间使用；出院需自备什么 |
| 纸尿裤、棉柔巾等清洁用品 | 是否供应、供应量及费用；不足时如何补送 |
| 护理垫、刀纸及分娩专用耗材 | 哪些由医院按诊疗使用，哪些要求家庭自带；具体规格和数量 |
| 水奶或配方奶、奶瓶及喂养用品 | 有补充喂养需要时由谁评估、供应和指导；领取、计费、自带及清洁规则 |
| 热水、热水瓶、饮水杯、餐具 | 病区有哪些可用设施；哪些要自备；订餐、取餐及清洗地点 |
| 吸奶器及配件 | 是否可借用；个人接触配件是否另备；清洁和收费要求 |
| 陪护床、被褥、储物设施 | 是否提供或租借；使用时段、费用和退还办法 |
| 洗漱用品、拖鞋、生活包 | 是否提供或有售；包含项目、是否另收费、能否使用自带用品 |

可直接询问：“我们将在这个病区住院，请给一份当次清单：哪些必须自带，哪些医院提供、借用或购买？提供的是否收费、能否带走？宝宝衣物、尿裤、护理垫和喂养用品分别怎么安排？”把答复日期、院区、病区和清单版本存到私人记录，不将个人沟通结果外推为全院规则。

## 住院期间注意事项

### 入病区当天：必须确认

以下是家庭沟通清单，不是对医院现行探视制度的转述：

- [ ] 请护士介绍呼叫铃、护士站及紧急求助方式；妈妈知道有不适时如何立即呼叫。
- [ ] 问清当天检查、治疗和查房安排；是否需要空腹、何时可吃喝、能否自行离开病区。
- [ ] 把过敏史、原有疾病和正在使用的药物告诉医护；自带药是否继续用由医护核对。
- [ ] 确认陪护人数、证件或凭证、轮换和夜间规则；探视及物品补送按病区当次要求。
- [ ] 问清热水、用餐、洗漱、垃圾分类及电器使用要求；保持通道通畅，减少贵重物品。
- [ ] 了解宝宝离开病房做检查或护理时的身份核对和交接流程，有疑问先向护士站核实。

### 分娩及术后：配合医护，不自行套用时间表

- **饮食与活动**：待产、麻醉和手术前后的进食、饮水及活动时间按当次医嘱。首次下床先请护士评估并安排陪同，不因想“早活动”勉强独自行走。
- **清洁与排尿**：按护理指导保持会阴清洁、及时更换卫生用品，留意排尿情况；有尿管时请护士指导，不自行处理管路。
- **不适及时报告**：出血增多、恶露异味、排尿困难、疼痛明显或其他不适，及时呼叫医护，不自行判断都是正常产后反应。
- **休息与情绪**：爸爸负责资料、补货和家人消息，减少探视干扰；保持环境舒适，情绪持续低落或难以承受时主动向医护表达。

上述护理方向参考医院《产后护理》（WHZJU-POSTPARTUM-001）。该文页脚保留较早更新标记，本页只采用一般护理与求助原则，不照搬其中固定的术后进食、下床、洗澡时点或药物用法；具体执行由当次医护评估。

### 喂养：需要帮助就及时提出

- [ ] 希望母乳喂养时，向护士申请姿势、含接和喂养观察指导；困难及时反馈。
- [ ] 若医护判断需要补充喂养，问清安排和供应方式，不自行等待网上流传的固定时长。
- [ ] 奶粉、奶瓶、吸奶器是否携带和使用，结合喂养安排、病区要求及清洁条件确认。

喂养原则沿用 CN-BF-001；这不构成该院“禁止自带奶粉”或“统一免费提供水奶”的结论。镇痛、陪产、护工及收费的详细问题见[分娩前行政准备](./分娩前行政准备.md#分娩与住院服务入院前逐项确认)。

## 出院前：必须完成交接

- [ ] 向医护确认妈妈和宝宝各自的出院安排、复诊事项、待出结果及需要立即求助的情形；不按预备物品的天数推算出院时间。
- [ ] 听清出院用药及护理说明；不明白的内容当场复述核对。
- [ ] 核对结算明细，保存出院记录、票据及医院交付资料到私人位置。
- [ ] 确认出生医学证明及其他必要出生资料的领取方式和后续事项，参见[出生资料清单](../07-执行清单/出生资料清单.md)。
- [ ] 归还借用物品，确认哪些可带走，整理母婴出院衣物及返家交通。
