# 宝宝保障

## 适用阶段

宝宝出生后按当地要求办理，具体名称、时间和材料以当地官方渠道为准。

## 目标

提前确认宝宝相关保障事项，避免错过办理时间或材料要求。

## 准备清单

- [ ] 查询当地办理渠道。
- [ ] 确认办理时间要求。
- [ ] 准备出生相关资料。
- [ ] 准备父母身份证件。
- [ ] 准备家庭相关资料。
- [ ] 记录线上或线下办理方式。
